## Guided practice across all five lessons

[DsaPractice](src/learn/components/lesson-labs/DsaPractice.jsx) is a shared presentation component that imports no practice dataset. Each lesson passes only its own file under `src/learn/data/practice/<stable-id>.js`. The five curated sets contain 50 distinct official problem links, each with a verified ID/title/difficulty, original learning focus, optional hidden hint, changed-condition transfer prompt and prerequisite where needed. This selection's ten-per-topic count is incidental; the [practice standard](docs/teaching/DSA-PRACTICE-STANDARD.md) explicitly rejects quotas and universal interview guarantees.

Foundation/core work fits the lesson; extensions are initially closed and name the additional skills. Contract differences are explicit: first versus all matching nodes, duplicate BST policies, cells versus edges, or a heap approach that does not meet a stronger follow-up bound for every parameter. Problem links open a new tab with safe link attributes and an accessible announcement. These sets supplement the existing complete local exercises and do not add an in-page judge, external submission automation or persisted practice-completion tracking.

The practice standard also maintains an evolving map for later DSA authors: boundary/prefix/window reasoning, binary search, sorting/intervals, recursion/correctness, backtracking, DP, greedy reasoning, union-find, weighted paths/topological work, range structures, deeper hashing/string matching and mixed/unseen review. The [weighted-path/topological destination note](docs/teaching/topic-notes/shortest-paths-spanning-trees-topological-ordering.md) preserves the specific frontier and active/finished-state transfer requirements. Bit-manipulation ownership remains an explicit scoped gap in [the unassigned inbox](docs/teaching/topic-notes/UNASSIGNED.md), without adding or auditing topics in this increment.

No full editorial, platform solution execution, submission or whole-video viewing is implied. Models and complete native example strings stay with the topic that owns them, while small presentation helpers may be shared. The presentation component's shared CSS does not require loading all five datasets. Source organization must preserve complete learning content and meaningful topic-specific labs.

- [review-module-order.cjs](scripts/review-module-order.cjs) regenerates fresh source-based inventory, derives the leading published DSA prefix, completes those actual lessons, verifies each completion count without silent advancement, then checks the next planned topic and resume target. Shared helper chunks are allowed by their real build imports, not guessed hashed filenames. Existing delayed/stale/error/retry/reload cases remain.

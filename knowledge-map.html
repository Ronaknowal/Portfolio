05 Reinforcement Learning ▾
Foundations
MDPs, Bellman Equations & Dynamic Programming Foundation
The mathematical framework: states, actions, rewards, transitions. Bellman equations define optimal value functions recursively.
Gymnasium
Value Iteration & Policy Iteration Foundation
Tabular DP algorithms for small MDPs — conceptual foundation for understanding all approximate methods.
Monte Carlo & Temporal Difference (TD) Methods Foundation
MC uses full returns; TD bootstraps from estimates. TD(0), TD(λ), and eligibility traces bridge the two approaches.
Q-Learning & SARSA Foundation
Off-policy (Q-learning) vs on-policy (SARSA) TD control — Q-learning learns the optimal policy regardless of exploration behavior.
Exploration vs Exploitation (ε-greedy, UCB, Thompson Sampling) Foundation
The fundamental RL dilemma — balancing gathering information with maximizing known reward. Bandits are the simplest setting.
Deep RL

Neural Q-learning with experience replay and target networks. Rainbow combines 6 improvements: prioritized replay, dueling, distributional, noisy nets, multi-step, double DQN.

Directly optimize the policy via gradient ascent on expected return. REINFORCE is the simplest; A2C adds a value baseline.

Clips policy updates to prevent destructive large steps — the workhorse algorithm for games, robotics, and RLHF.

Meta-Learning Problem Formulation Foundation

22 Key Terminology Glossary ▾
Arithmetic Intensity
Ratio of compute operations to memory accesses (FLOPs/byte). Determines whether a kernel is compute-bound or memory-bound.
FLOP Utilization (MFU)
Model FLOP Utilization — fraction of theoretical peak hardware FLOPs actually achieved during training. 40-60% is good for LLMs.
Scaling Laws
Power-law relationships between compute, data, parameters, and model performance. Guide resource allocation for training.
Chinchilla-Optimal
The compute-optimal ratio of model size to training data (~20 tokens per parameter), from DeepMind's Chinchilla paper.
Emergent Abilities
Capabilities that appear unpredictably at certain model scales — contested whether truly discontinuous or measurement artifacts.
Grokking
Phenomenon where models memorize training data, then suddenly generalize long after achieving zero training loss.
Mode Collapse
Generator produces limited variety of outputs, failing to cover the data distribution. Common in GANs; analogous issues in RL.
Reward Hacking
Agent exploits flaws in the reward function to achieve high reward without solving the intended task.
Sycophancy
Model agrees with or flatters the user rather than giving honest/accurate responses — an alignment failure mode.
Catastrophic Forgetting
Neural network loses previously learned capabilities when trained on new tasks — the central challenge of continual learning.
KV-Cache
Cached key and value tensors from previous tokens during autoregressive generation — avoids redundant computation but consumes significant memory.
Perplexity
Exponential of cross-entropy loss — measures how "surprised" a language model is by test data. Lower is better.
Overparameterized
Model has many more parameters than training examples — counterintuitively, this helps generalization in deep learning (double descent).
Double Descent
Test error first decreases, increases (classical regime), then decreases again as model size grows far beyond interpolation threshold.
Mixture-of-Experts (MoE)
Architecture with many expert sub-networks, routing each token to a subset. Scales total params without proportional compute increase.
Token
Subword unit produced by tokenizer — typically 3-4 characters in English. The atomic unit LLMs process.
Inference-Time Compute
Additional computation during generation (not training) — extended thinking, beam search, verification. Key to o-series and R1.
RLHF
Reinforcement Learning from Human Feedback — train reward model on human preferences, then optimize LLM via PPO against it.
DPO
Direct Preference Optimization — skip reward model, directly optimize on preference pairs. Simpler alternative to RLHF.
LoRA
Low-Rank Adaptation — add small trainable matrices to frozen weights. Train <1% of parameters with near-full fine-tuning quality.
Flash Attention
IO-aware attention implementation that tiles computation to SRAM, avoiding materialization of full N×N attention matrix. 2-4× faster.
Speculative Decoding
Small draft model proposes tokens verified by large model in parallel — lossless speedup for autoregressive generation.
Activation Checkpointing
Trade compute for memory by recomputing activations during backward pass instead of storing them. Enables larger batch sizes.
RoPE
Rotary Position Embedding — encodes position by rotating query/key vectors. Dominant positional encoding in modern LLMs.
SwiGLU
Activation function: SiLU(xW₁) ⊙ (xW₂). Standard FFN activation in modern transformers (LLaMA, Gemma, etc.).
RMSNorm
Simplified LayerNorm using only root-mean-square, no mean subtraction. Faster and equally effective. Standard in modern LLMs.
Attention Sink
First few tokens in context receive disproportionate attention — important for streaming inference and context window management.
Hallucination
Model generates plausible but factually incorrect information — a fundamental challenge in deploying LLMs for factual tasks.
Distillation
Training a smaller "student" model to match a larger "teacher" model's outputs, transferring knowledge to a more efficient model.
Data Contamination
Benchmark test data appearing in training data, inflating evaluation scores. Growing concern with web-scale training.
Alignment Tax
Performance reduction on capability benchmarks caused by safety/alignment training (RLHF, etc.).
Loss Spike
Sudden increase in training loss, often from bad data batches or numerical instability. May require learning rate rollback.
μP (Maximal Update Parameterization)
Initialization and learning rate scheme that allows hyperparameters to transfer across model scales — tune on small models, apply to large.
Auxiliary Loss
Additional loss term beyond the primary objective — used in MoE for load balancing, or in multi-task learning.
Soft Labels
Probability distributions over classes (vs. hard one-hot labels) — carry richer information, used in distillation and label smoothing.
Few-Shot Learning
Learning to classify or adapt from only a handful of labeled examples per class — the core evaluation setting for meta-learning.
MAML
Model-Agnostic Meta-Learning — learn an initialization that can be fine-tuned to any new task in a few gradient steps.
Episodic Training
Training procedure where each iteration simulates a small learning task — the model learns to learn by solving many sampled tasks.
Qubit
Quantum bit — exists in superposition of |0⟩ and |1⟩ simultaneously. The fundamental unit of quantum information.
Superposition
Quantum state existing as combination of multiple basis states at once — collapses to one upon measurement, enabling quantum parallelism.
Entanglement
Non-classical correlation between qubits — measuring one instantly determines the other. Essential resource for quantum speedups.
NISQ
Noisy Intermediate-Scale Quantum — the current era of quantum computing with 50-1000+ noisy qubits lacking full error correction.
Barren Plateau
Exponential vanishing of gradients in random quantum circuits — the major scalability challenge for variational quantum algorithms and QML.
Variational Quantum Circuit
Parameterized quantum circuit optimized by classical gradient descent — the quantum analog of a neural network layer.
Quantum Advantage
Solving a computational problem provably faster than any known classical algorithm — demonstrated for specific sampling tasks, debated for practical ML.
Hypernetwork
A network that generates weights for another network — used in meta-learning for rapid task-specific adaptation without gradient steps.
Goodhart's Law (in RLHF)
When a measure becomes a target, it ceases to be a good measure — central challenge in RLHF where reward model is an imperfect proxy for human preferences.
Lottery Ticket Hypothesis
Dense networks contain sparse subnetworks (winning tickets) that can match full accuracy when trained in isolation from their original initialization.
Representational Collapse
Different inputs map to identical or near-identical representations — a failure mode in self-supervised learning, MoE routing, and contrastive learning.
Loss Landscape Geometry
The shape of the loss function over parameter space — saddle points dominate over local minima in high dimensions; flat minima generalize better.
PAC Learning
Probably Approximately Correct — theoretical framework guaranteeing a learner finds a near-optimal hypothesis with high probability given enough samples.
VC Dimension
Vapnik-Chervonenkis dimension — measures the capacity of a model class. Maximum number of points it can shatter (classify all labelings correctly).
Deceptive Alignment
When a model behaves well during training to preserve misaligned objectives — appears aligned but has strategically learned to game the oversight process.
Mesa-Optimization
When a trained model itself contains an internal optimization process — the mesa-optimizer may pursue different objectives than the base training optimizer.
Model Merging
Combining multiple fine-tuned models in weight space without retraining — TIES, DARE, SLERP, and model soups produce multi-capability models cheaply.
Conformal Prediction
Distribution-free method producing prediction sets with guaranteed coverage probability — wraps any model to provide statistically valid uncertainty intervals.
Federated Learning
Train models across decentralized data sources without centralizing raw data — FedAvg aggregates local model updates while preserving data privacy.
No-Cloning Theorem
Fundamental quantum constraint: unknown quantum states cannot be perfectly copied — distinguishes quantum from classical information processing.
Quantum Annealing
Optimization approach using quantum tunneling to escape local minima — D-Wave systems implement this for combinatorial optimization problems.
QNLP
Quantum Natural Language Processing — maps compositional linguistic structure to quantum circuits using the DisCoCat categorical framework and Lambeq library.
Little's Law
L = λW — the average number of items in a system equals the arrival rate times the average wait time. Fundamental queueing theory result for LLM serving capacity planning.
TTFT / TBT
Time To First Token / Time Between Tokens — the two key latency metrics for LLM inference. TTFT depends on prompt processing; TBT on autoregressive decode speed.
Disaggregated Serving
Separate prefill (compute-bound) from decode (memory-bound) onto different hardware — enables independent scaling and optimal utilization for each inference phase.
Model Cascade
Route easy queries to small/fast models and hard queries to large models — confidence-based escalation that reduces cost 70-90% with minimal quality loss.
Data Flywheel
Production feedback loop: deploy model → collect user interactions → label high-value examples → retrain → redeploy. The compounding advantage that makes AI products improve with usage.
Prefill vs Decode
Two phases of LLM inference: prefill processes the prompt in parallel (compute-bound); decode generates tokens one at a time autoregressively (memory-bandwidth-bound).
Activation Steering
Modifying model behavior at inference time by adding learned vectors to hidden state activations — no fine-tuning, reversible, and composable.
Steering Vector
A direction in activation space that, when added to hidden states, shifts model behavior toward a specific concept or style. Typically computed via contrastive activation pairs.
Refusal Direction
A single direction in activation space mediating safety-trained refusal behavior — ablating it can jailbreak models, amplifying it strengthens refusals.
Representation Engineering (RepE)
Top-down approach reading and writing high-level concepts (honesty, refusal, emotion) directly in representation space rather than through prompts or fine-tuning.
Activation Patching
Replace activations from one forward pass into another to causally identify which model components produce specific behaviors — a core mechanistic interpretability technique.
Model Editing
Surgically update specific facts in a trained model's weights without full retraining — ROME, MEMIT, MEND modify MLP layers via targeted rank-one or rank-k updates.
Function Vector
Compact representation in hidden states that encodes a task being performed via in-context learning — extractable and transplantable for zero-shot task induction.
Concept Erasure
Removing specific knowledge or capabilities from a trained model — LEACE for linear concepts, gradient ascent for unlearning, used for privacy compliance and safety.

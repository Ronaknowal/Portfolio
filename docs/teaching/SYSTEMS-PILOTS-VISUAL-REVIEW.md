| Arrays, Strings & Hash Maps | The address formula used a generic three-box prose flow without showing consecutive storage. | Linked Lists, Stacks & Queues | A row of slots and prose required the reader to mentally connect wraparound to FIFO order. The ring shares the existing queue model; arrows are index progression, not stored next pointers. Size distinguishes head = next when empty versus full. No concurrency guarantee. |
| Hypothesis Testing & Confidence Intervals | The repeated-sampling lab teaches coverage well, but the worked interval's relationship to zero and a useful effect was text-only. The new view computes the five-pair t interval, not the simulation's known-variance interval; the colored threshold region is not probability mass. Practice now asks about a 2 ms shift so it is not the exact revealed example. |
| Bayesian Inference & Conjugate Priors | Density curves reveal uncertainty, but the two kinds of evidence and two separate parameter updates deserved a visible introduction. Add a static count/parameter figure. | Before the density lab, eight S circles and two F squares feed separate alpha/success and beta/failure arithmetic lanes: 2 + 8 = 10; 2 + 2 = 4. Explain why the posterior mean differs from the observed fraction. | Retain the prior/posterior distribution controls and formal derivation. Shapes are explicitly model parameters, not four additional observed visitors; observed outcome order is grouped for counting. No invented manipulation. |
| Spectral Graph Theory | The global spectrum lab already connects nodes and eigenvectors; the local Laplacian row still required mentally matching a formula to edges. Add a focused row inspector. | After the C-row equation, a three-neighbor graph links weights and signal values to individual signed contributions. Toggle constant versus two-group signal: C's row changes from 0 to 0.4 through its weak D edge. | Retain the global eigenvector/bridge lab. Only C's incident edges are drawn; E/F have zero entries in this row. Chosen signals need not be eigenvectors; a signed row result is distinct from squared whole-graph energy. Line lengths do not encode weights. |

All new views introduce their entities and legends, use values from the surrounding example, and include text/numeric equivalents. Interactive views expose concrete input changes and restore their original state. Shapes, labels and text complement color. No decorative chart or benchmark was added.

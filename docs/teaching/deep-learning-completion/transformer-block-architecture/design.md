The complete prepared manuscript is the content source. Its correction of historical universal architecture claims, constant sum-after-LayerNorm diagnostic, and unretained benchmark plots is preserved. Title, route, curriculum order and existing publication path remain unchanged.

The visual specification's reference-frame dot plots are implemented as aligned signed bars with printed values and denominator table, preserving exact sign and common-scale comparisons. Measured fits use a selectable exact history plus the complete six-row result table; there is no invented test history. Native programs are downloaded from canonical byte-identical files; all three displayed code blocks were executed. Full original datasets and records remain available for offline reproduction; compact runtime assets contain exact selected weights and needed measured curves. They are fetched only when their section nears the viewport, with abort/retry and visible loading state.

The author reviewed reading progression, each concept transition, independent practice, original-versus-edited data labels, plot units and null/contrast fixtures. Existing caution homes and deeper-branch boundaries remain. All transformations and recorded values use actual calculations. No prediction entry or answer-unlock feature exists. Browser geometry/keyboard checks, independent review and final integration are separate remaining root-owned stages; this author record does not certify those.

Native checks use the installed Python 3.12.14, NumPy 2.3.5 and PyTorch 2.14.0 CPU. Current complete code includes outputs, input/parameter gradients and equal SGD updates for both reference placements. Both retained display checkpoints are re-evaluated on all 60 test rows. Historical six-fit training histories are reused unchanged rather than claiming a refit. JavaScript port checks cover every exact whole-block stage, both retained models, every saved intervention, all saved per-layer tensors and numerical failures. The GELU approximation's small error is bounded by the observed 1e-4 float32 checkpoint tolerance.

Scope deliberately keeps canonical raw data/downloads as reproducibility assets. Browser inference is bounded to at most 60 records and never trains. There is no GPU/distributed performance claim.

Browser review correction: operation lists alone did not expose paths. Connected SVG diagrams now show the actual pre/post bypasses and sum junctions, attention edges crossing position lanes versus local shared FFN edges, and sequential versus parallel fork/join dependencies. Original operation text remains accessible as a companion. The full 24-feature intermediate-stage dump is optional, retaining the current trajectory and output prominently. Narrow-screen grids use minmax(0,1fr) and child min-width zero to keep tables within local scrolling. The new scoped neutral theme replaces inherited green surfaces only for this implementation. Deployment uses an explicit learner-download allowlist; manuscripts, authoring design/specifications and unused verifier fixtures are not copied to public.

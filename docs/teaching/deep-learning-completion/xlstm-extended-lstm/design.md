## Author learning-experience checklist

- The need is introduced before each mechanism: missing evidence motivates state, competing writes motivate normalization, overflow motivates shared scaling, addressed payloads motivate a matrix, and old/local information motivates the chunk boundary.
- Four investigations have distinct questions and immediate calculated defaults. No learner prediction field, answer unlock, grader or compute gate exists. Native model predictions are scientific results, not required learner responses.
- Controls change real inputs or execution settings. XA's log-offset null, XB's zero query/value and reversed-key contrast, XC's size/carry/future/null tests and XD's edited/reversed/blank/carry/reset cases are observable in both intermediates and outputs. The matrix digit model may retain its argmax while changing logits; the UI does not force a class-change story.
- Full numerical traces remain available, while current output, selected state and a meaningful path stay visible. Long matrices, code and optional exact tables do not replace the first-pass explanation.
- Complete scratch and normal NumPy/PyTorch routes are locally explained. A real small experiment, all six seeds/models, full selected-checkpoint replays and actual optimizer evidence are retained. No official pretrained/GPU execution, new fit campaign or unseen video review is claimed.
- Scientific geometry uses the actual values, signed scales and operation dependencies. Singleton selection/checkpoint series render as marked circles, not invisible one-point polylines. Every plot has exact accessible values and named axes. Full matrices use local keyboard scrolling at nominal width.
- Program/data downloads use an explicit allowlist and equal their canonical files byte-for-byte. Compact initial display inputs are lossless selected values; selected model assets and the300-image bank load near the relevant figure/lab. Author/private numerical fixtures are not deployed.
- Edits, source selection, state selection, execution settings and pinned comparisons live above asset loading. Model changes and failed/retried requests do not reset them. Stale asynchronous resources are name-bound and aborted. Error text is actionable and omits raw parser output.
- All64 pixels support roving arrow-key focus and exact integer input; intensity8 and above use black labels, lower intensities white. Controls use the opt-in neutral number component. Layout uses minmax(0) and bounded nominal scientific regions. Final painted geometry and interaction remain for root browser review.
- Practice, mathematical depth, research boundaries and the full manuscript are preserved. Closed initial solutions are independently checked by the render script.

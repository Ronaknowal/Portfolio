## Representation contracts

All numbers derive from the described finite matrix/graph model. No plot is a measured performance benchmark or a force-layout distance claim. Arrows show mathematical direction; edge labels show weights even when line width provides a redundant cue. Every figure has a plain caption, explicit node labels, keyboard-equivalent controls and readable 390/320 layouts.

1. **Graph/matrix and walk workbench**, after matrix construction: weighted undirected/default and directed preset, optional bridge/extra edge, selected endpoints and k=1–3. Active matrix cells and actual intermediate walks use the same model. No arbitrary graph editor is needed for the bounded teaching question. Reset returns the stated fixture; live changes clear stale selections. Matrix rows can scroll locally with keyboard focus on narrow screens.
2. **Directed-components inline figure**, at strong/weak definitions: A→B↔C, one weak component but two strong components; accompanying reachability table includes reflexive entries. The double arrow is two actual directed edges, not an undirected relation.
3. **Laplacian/energy investigation**, immediately after the worked row: controls change actual node signals and bridge weight, show weighted endpoint differences, selected-row signed sum and nonnegative whole-edge energies. A componentwise-constant preset distinguishes zero energy from globally equal values. Include exact-value text beside visual encodings.
4. **Incidence inline figure**, at factorization: map a node signal to signed edge drops, weighted flows and back to node net outflow. Mark matrix shapes; reversing an orientation is a convention, not deletion of one direction from an undirected edge.
5. **Normalization workbench**, at isolate/self-loop discussion: same matrix under L, S and R, explicit selected vectors and isolate row. Never silently fill NaN with a displayed zero; zero inverse degree is the declared convention. Self-loop counts once in row-sum degree, distinct from the combinatorial convention of counting two incidences.
6. **Averaging trajectories**, after one hand step: node-colored trajectories versus discrete step, exact current values and both conserved sums. Control method and justified timestep presets; step/reset are deterministic and bounded. Current model is scalar linear averaging with no neural weights/nonlinearity or physical time calibration.
7. **Anchored interpolation**, beside energy minimization: fixed values use an anchor glyph and editable boundary value; unknowns are shown as unknown when a whole component lacks an anchor. Toggle a bridge or additional anchor; solved values are rounded and residuals independently checked. It is an assumed smoothness model, not evidence that a real missing sensor is necessarily harmonic.
8. **Data-availability inline comparison**, at graph evaluation: concrete time-ordered relationships and prediction-time cutoff; label the prohibited future edge instead of claiming every graph connection to a test vertex leaks. No decorative network added outside this explanatory job.

## Outcomes, route and representations

1. Read a signal as one value per node and a Laplacian row as weighted differences; explain units and compute the C row. Existing graph/row inspector exposes precisely this correspondence.
2. Derive nonnegative energy, kernel dimension and the Fiedler variational property from an orthonormal expansion. Retained bridge/mode lab exposes changing eigenvalues, mode values, edge energy and residual; predict bridge removal/global scaling before controls. All outputs share the same state. Displayed zeros versus numerical tolerance remain explicit.
3. Distinguish cut weight from balanced cut quality. A cut-set investigation colors actual sides/crossing edges and aligns counts, volumes, RatioCut, Ncut and conductance. Sorted normalized coordinates with a movable threshold show the exact candidate partition; a companion table compares every candidate. Include ties, sign reversal and arbitrary nonempty partitions. Small fixtures permit exhaustive oracle comparisons; general algorithms do not enumerate every partition.
4. Explain D-weighted geometry and normalized zero modes. Inline same-graph coordinate rows connect v to y=D⁻¹/²v and the weighted constraint. Formula and isolate counterexample are adjacent. Cheeger lower-bound proof and upper-bound sweep interpretation must specify connected positive-degree weighted assumptions and use normalized eigenvalues.
5. Form k eigenvector columns, treat each node's row as a point, normalize and cluster. A three-community graph and two-coordinate projection of its three-dimensional row embedding show node identity, norms, selected row and changed centroid assignments. Clearly label the projection; exact all-coordinate rows remain accessible. A stepper reveals nearest-centroid assignment then means, not unrelated narrative steps. Graph strength changes rebuild/reset the full trace. The three-dimensional distances, not projected chart distances, decide clusters.
6. Filter a concrete node signal. Separate linked coefficient/gain strips and before/after node values make Uᵀx → gain → U result visible. Compare heat, ridge and hard spectral cutoff; vary time/strength, signal and bridge, restore preset. Values are deterministic equations, not measured sensor data or simulated benchmark. Explain energy versus signal squared norm and repeated-eigenspace boundary dependence.
7. Connect heat to conserved means and spectral rate, and distinguish a discrete bipartite walk. An inline two-node transition diagram supports the counterexample without inventing another full lab. Establish why a scalar spectral filter is basis invariant within a repeated eigenspace.
8. Explain effective resistance via injected/extracted unit current, potentials modulo constants and a spectral sum. An inline bridge/parallel-route figure labels currents/voltage and separates graph similarity from actual conductance. Complete numerical solve validates the unusual application and its assumptions.
9. Diagnose wrong affinity, units, normalized conventions, residual-only acceptance, eigengap overinterpretation and sparse solve choices; use changed independent tasks with separate hints and explained solutions. Finish with the actual next topic, Combinatorial Optimization & Approximation Algorithms.

All important mechanisms must already be visible in ordinary reading order; no reliance on finding a hidden later lab state. SVG geometry uses restrained amber/blue identity and readable labels with local scrolling only where actual dimensional structure requires it. Tables remain keyboard-accessible exact companions. No lab count is a quality metric.

## Visual teaching contracts

Every investigation supports prediction, meaningful controls, explanatory output, transfer and reset. Exact states have text equivalents. Desktop/narrow layouts and keyboard controls must be checked.

1. **Testing execution:** compare early return against full accumulation on a singleton, two readings and zero. Step through consumed/unconsumed readings, total and return. Predict why a singleton can conceal the bug. Python tracing provides the independent oracle.
2. **Test discrimination:** choose boundary/reference/property cases; see which intentionally wrong temperature functions survive. Explain why a difference property misses an offset. The three candidate implementations are not exhaustive possible defects. Native unit tests establish each result.
3. **Dependency constraints:** two invented direct packages constrain a shared dependency. Change one requirement; highlight accepted candidate versions and the intersection. Explain an empty intersection rather than recommending forced installation. Exhaustive finite set intersection is the oracle; real pip documentation supplies the qualified connection.
4. **Notebook document/kernel:** edit offset without execution, run cells independently, restart, then run all. Show source, stored variables and saved output separately. Counterexample: restart clears names but saved output is historical. Real kernel checks complement fixed-cell Python execution.
5. **Random consumers:** an explicit finite tape feeds two consumers through a shared cursor or separate cursors. Insert an extra preprocessing draw and observe whether the model's next draw changes. This is a consumption model, never numerical imitation of NumPy. Real spawned NumPy generators verify stream independence separately.
6. **Provenance:** vary input bytes, offset or code revision with a cache key using only filename versus complete declared ingredients. Show changed result and changed identity separately. Same-mean/different-data case diagnoses why comparing results is insufficient. SHA-256/native replay validates byte distinctions, without claiming semantic equivalence.
7. **API boundary:** trace decoded candidate through type, finite/range validation and filtering. Bool, zero, threshold equality and invalid low score expose different stages. Python loader is the native oracle; browser labels predecoded small fixtures, not arbitrary JSON parsing.
8. **Ownership:** repeat calls under shared default, caller mutation or copied input; references and list contents reveal which object changed. Reset restores definitions and fixtures. Native object identity checks verify aliasing. Copies are shallow.
9. **Compatibility:** select a changed default, keyword name, unit or inclusive threshold; an unchanged caller travels through binding then execution then contract comparison. Native calls distinguish TypeError from silently changed results. Model covers these four concrete revisions, not a universal compatibility analyzer.

## Learning contract and scope map

The learner already has loops, arrays, maps, linked lists, sorted merging, heaps, binary search trees and asymptotic reasoning from the completed DSA sequence. Recap cache pages, dirty state, file reads and durability locally rather than assume a database course. SQL is a useful recorded prerequisite, not a reason to skip those mechanisms.

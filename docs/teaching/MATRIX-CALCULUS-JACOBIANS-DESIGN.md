## Visual contracts

- Local-approximation plots use the exact original polynomial along x+t·v. Horizontal axis is t; vertical is change in one named output from f(x). Gold is the actual polynomial, dashed blue its tangent prediction. Curves are calculated, not fitted or empirical; equal scales within each comparison, separate explicitly labelled output scales if their ranges differ. Current step marks two points; exact values and error remain available. Default x=(2,3), v=(1,−2), t=0.25; t=0.01 reproduces the original. Controls apply immediately and reset deterministically.
- Forward/reverse trace uses A=[[1,2],[−1,1]], elementwise square and L=q·z. Default x=(1,2), q=(1,−1), input direction v=(1,0). Draw arrows in their actual computation direction; forward values are separate from tangent/gradient annotations. Selecting mode changes the question, not the underlying function. Explicit scalar-seed and fan-out accumulation explanations avoid treating the transpose as an inverse.
- Affine contribution view uses a small two-example/two-feature/two-output fixture for readable cells. A selected weight traces matching X and incoming G values; a bias traces all rows. Switch sum/mean objective scaling and change one target/input through named fixtures. Exact sums and shape labels explain dependence; full 4×3 example stays in the lesson. Inputs are bounded presets, not a general training system.
- Difference check varies smooth x³ versus |x|, base point and powers of ten h. Plot/table finite differences are computed using browser IEEE-754 numbers; label underflow/cancellation and unavailable true derivative at the kink honestly. It is a diagnosis tool, not a benchmark or a universal best-h picker.
- Inline figures introduce Jacobian row/column meanings, branching accumulation, shared bias replication/gradient sum and noncommuting matrix-square terms where needed. No figure quota. Mobile keeps equations legible and stacks connected plots; use labelled local scroll only when exact matrix geometry warrants it.

## Learning and engineering checks

- Each addition answers which mechanism it replaces in ordinary use, the exact API settings/state, what was held fixed, what the actual comparison showed, and what remains different.
- Each has a complete downloadable program with install/run commands, a lazy readable code view and actual recorded output; no code is advertised as running in-browser.
- Changed-constraint practice has an explained answer and distinguishes executed variations from proposed learner runs. It has no prediction gate or optional learner-prediction feature.
- Existing mechanisms are retained rather than replaced by package calls. Library/dependency versions, exact-fit versus sampling tolerances, algorithmic costs and known limits are visible in the lesson.
- Stable arithmetic uses QR stabilization, Cholesky solves/log determinants, sparse Laplacian products and cached pair distances. Numerical comparison avoids vector sign/basis ambiguity and arbitrary cluster labels.
- No runtime dependencies were added to the browser bundle, no shared registry/global CSS/manifest was changed, no build/server was started, and no central ledger was edited.
- The seven destination notes now distinguish completed author remediation from pending independent review/integration. Their historical findings and earlier unrelated resolutions are retained.

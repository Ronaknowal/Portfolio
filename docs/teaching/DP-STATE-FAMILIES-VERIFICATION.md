## Existing teaching and actual missing scope

The previous section 8 named three families without deriving or implementing them. The extension now develops each from its boundary contract, proves why that state suffices, gives the recurrence, bases, evaluation order, reconstruction, complexity and changed practice. It does not add specialized DP optimization theorems or claim to guarantee every interview problem.

- **Interval:** fixed matrix result shapes make internal regrouping replaceable; a final split separates two shorter intervals. An ordered expression tree becomes an executable postorder witness. The balloon transfer fixes surviving boundaries and recovers removals in child-before-parent order, with zero-valued objects and signed-required-removal diagnosis distinguished.
- **Tree:** weighted independent set exports a parent-selected permission. The proof uses the absence of cross-child edges, not a binary-search ordering property. The native implementation validates a simple tree, computes iteratively and propagates the actual parent choice when recovering IDs. Negative/empty cases and the changed nonempty requirement are explicit.
- **Digit:** position, tightness, padding/start status and used digits describe permitted continuations under one fixed bound. The lesson derives the partition/count recurrence, inclusive-range subtraction, endpoint zero convention and exact integer costs. A changed adjacent-equality rule requires previous-digit state rather than the used set.

The stable title, order and next-topic Range Queries bridge remain. The local tree branch reviews its prerequisites; the individual brief adds Trees & Binary Search Trees while the parent manages shared prerequisite metadata. The three incoming gaps are implemented in their existing DP owner; no unrelated bitwise or optimized-DP expansion was introduced. The parent owns the shared destination-note and coverage-map disposition.

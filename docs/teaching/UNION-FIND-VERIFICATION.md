## Deliberate boundaries

Ordinary DSU does not supply original routes, shortest distances, directed reachability, arbitrary edge deletion, concurrent correctness or permanent historical version IDs. Rollback is an explicit optional design without compression, not an implicit deletion capability. Potential/parity DSU is identified as a further variant requiring composed edge metadata; it is not claimed to be implemented by the ordinary class. The inverse Ackermann sequence bound is distinguished from the locally proved size-doubling bound. No universal mastery or exhaustive-interview guarantee is made.

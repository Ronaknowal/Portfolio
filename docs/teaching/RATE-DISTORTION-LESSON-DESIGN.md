## Contract, scope and preservation

Retain **Rate-Distortion Theory**: the title already promises the frontier, its derivation and its practical meaning. Preserve the fair-binary calculation and its complete original Python program byte for byte, with its explicit D≤.5 domain; preserve the audio workflow, distortion-choice caution and representation-learning connections. Repair the temptation to extend `max(0,1-Hb(D))` past .5, where it incorrectly rises again. Preserve no unsupported performance ranking.

Readiness: Entropy, Cross-Entropy & KL Divergence and Mutual Information & Information Bottleneck. Locally refresh a conditional probability table, weighted error, logarithm units and a constrained minimum. Explain the convexity and Gaussian variance arguments here rather than requiring an unexplained optimization detour. Follow MI in the actual module order and bridge next to f-Divergences & Integral Probability Metrics.

The beginner finish line is an actual encoder → transmitted index → decoder, average versus worst-case error and a valid comparison against a limit. Intermediate readers derive the binary frontier, explain the coding theorem and optimize a finite reproduction alphabet. The deeper route derives Gaussian allocation, distinguishes fidelity from distribution matching, and makes the connection to actual entropy-coded learned compression with the necessary caveats. There is no promise that a finite code, BA table or neural bottleneck automatically attains Shannon's limit.

## Representation contracts

Use separate forms for separate questions: the codec is a table of bit strings and changed positions, the frontier is a mathematical graph, BA is an evolving conditional matrix, and Gaussian allocation is a pair of variance reservoirs. Keep those entities visible in the initial states. Inline channel/codec and fidelity figures introduce relationships at their first use; labs supplement those explanations. No lab/diagram count is a teaching requirement.

All quantitative plots are **calculated**, with their stated model, dimensions and units. Binary curves use the correct piecewise analytic function; finite code points come from exhaustive enumeration, not a purported codec benchmark. Gaussian rates are model predictions for iid Gaussian vectors, not measured compression. BA draws its own computed states and reports objective bounds/iteration caps; it does not assert that a fixed number of steps converges.

Bound inputs and work: binary words have length3; table≤8 rows; finite optimizer≤6 source/reproduction symbols, bounded finite costs and iterations, log-domain normalization and cached traces. Recompute on meaningful edits, never per animation frame. No external video/embed downloads, timers or large graph dependencies. Only this topic imports its model, examples and styles. Labels and tables supplement colour; buttons use native focus, explicit names, disabled ends, full resets and actual back states. At320px preserve bit relationships, stack controls and use internally scrollable full tables only where necessary. Graph labels must remain readable instead of scaling a desktop figure indefinitely.

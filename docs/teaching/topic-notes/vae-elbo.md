- Useful connection: the mathematical VI lesson now provides a complete Normal example in which shared parameters map each x to a different q distribution: prior N(0,1), observation noise variance1 gives q(theta|x)=N(x/2,.5) and new-measurement predictive variance1.5. A restricted constant-mean encoder can have an amortization gap even when a per-case Gaussian family can represent each true posterior. A representable encoder can instead have no unavoidable amortization gap. More stochastic draws do not remove a family or encoder restriction.

Teach what stays fixed during a variational comparison versus joint learning of a data model and inference network. A learned decoder's output mean alone is not the full posterior-predictive distribution.

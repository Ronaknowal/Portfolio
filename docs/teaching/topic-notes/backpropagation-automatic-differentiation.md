- Proposed treatment: explain that central differences combine a smooth-function truncation term with amplification of function-evaluation error by division by the perturbation. Choose scales and tolerances appropriate to the function, parameter units, dtype and derivative magnitude. Sweep several perturbations, use absolute as well as relative error near zero, and control randomness and state during paired evaluations. Address nondifferentiable branches and memory aliasing when relevant to the actual engine. Agreement on tested inputs supports those cases; it is not a proof of every primitive, graph or boundary condition.
- Concrete reason: a single perturbation cannot certify a universal relative error. For the smooth function `f(x)=1e12+x` at `x=1`, binary64 evaluates `f(x+1e-5)` and `f(x-1e-5)` to the same value, producing a zero central difference although the derivative is one. Executed in the workspace's Python 3.12.14 during design preparation: both samples were `1000000000001.0`, and the central difference was exactly zero. Reproduce this in the destination's actual runtime before using it there. This does not claim that the current neural-network example fails.
- Ownership: Numerical Methods owns the local error balance and scalar/directional checking interpretation. Backpropagation is the better home for primitive coverage, repeated paths, broadcasting, graph accumulation, framework comparisons, dtype-specific checks and distinguishing derivative conventions at nonsmooth points. Its author should adapt this bridge to the actual engine and include varied independently checked cases.
- Primary evidence inspected 10 September 2026 UTC: Driscoll and Braun, [Convergence of finite differences](https://fncbook.com/python/fd-converge/), sections 5.5.1–5.5.2, develops Taylor error and cancellation; [PyTorch 2.14 gradcheck](https://docs.pytorch.org/docs/2.14/generated/torch.autograd.gradcheck.gradcheck.html), signature and notes/parameters, specifies double-precision-oriented defaults and qualifications for nonsmooth points, overlapping storage and nondeterminism.

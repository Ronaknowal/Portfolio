# Incoming from Geometry, Trigonometry & Coordinate Reasoning

Status: open for destination assessment, 2026-09-11. Origin Geometry45 is author-verified; independent integration remains parent-owned. Assess when authoring this destination. Evidence: [Geometry verification](../GEOMETRY-TRIGONOMETRY-VERIFICATION.md).

Geometry teaches scalar 2D active rotation about an origin, passive conversion q = R(-theta)(P-O), inverse reconstruction P = O + R(theta)q, and why translation affects points but not free displacements. Its only prerequisite is Algebra; do not reverse the existing Geometry → Vectors dependency.

In this destination, use that physical-point-versus-description distinction to introduce named 3D frames, subscript conventions, handedness, transformation order and orientation representations. Explain what each map consumes and returns before compact homogeneous matrices. Revisit the learner's reconstruction check with changed frame chains. Geometry's screen example is an affine axis/scale convention, not camera projection or calibration.

Reason: a correct rotation matrix alone does not tell a beginner whether an object moved, coordinates changed or an origin translated. The destination owns full robotics conventions and 3D extension.

- Source-specific mechanism: the official V4.1 report §2.2 projects decoder global entries from the final causal-encoder state using layer-dependent maps; local sliding-window K/V remain layer-local. Section 2.3 separates Full, Reindex and Reuse modes: cache sharing can coexist with newly computed selection, while Reuse also shares the selected indices. Each layer still computes its own query/output. Later decoder indexers search a bounded candidate pool, but the first one still scans the causal range. Section 2.2 motivates bounded local replay through an effective-receptive-field observation; it is not a proof of arbitrary full-network exact equality.

## 2026-09-11 — Separate the state response, feedthrough and held-input integral

- Status: addressed in prepared content; runtime implementation pending
- Origin: Ordinary Differential Equations & Linear Systems, [scoped design](../ORDINARY-DIFFERENTIAL-EQUATIONS-LESSON-DESIGN.md), while locating the matrix-exponential teaching owner.
- Destination and rationale: this existing sequence-model lesson owns how continuous linear systems become token updates. ODE50 will teach the general solution and a small exact held-input example; model-specific S4/Mamba conventions and implementations should be reconciled here by its future author.
- Existing coverage: published but not reviewed in the current mathematics rollout. The actual source `src/learn/data/topics/state-space-models-s4-mamba-mamba-2.jsx`, section 3.1, defines `h(t)=C exp(At) B + D delta(t)` and then writes `y=(h*u)+Du`. These conventions count the feedthrough twice. The same paragraph's complete-output wording suppresses the initial-state response without declaring a zero initial state. Section 3.2 writes an inverse-based held-input formula without restricting it to nonsingular A.
- Proposed treatment: choose one impulse-response convention consistently. For an ordinary input on t>=0, write `y(t)=C exp(At)x0 + integral_0^t C exp(A(t-s))B u(s) ds + D u(t)`. Either define the strictly proper kernel `g(t)=C exp(At)B` and add Du once, or include `D delta` in the full causal distributional impulse response and do not add Du again. State zero initial conditions explicitly when deriving input-output convolution alone. Introduce the distributional convention only if needed by that branch.
- Concrete diagnostics: C=0, D=1 must give y=u, whereas the two current displayed expressions together give 2u. With u=0 but Cx0 nonzero, zero-state convolution alone loses a real initial response. With A=0 and B=1, the exact held-input update is `x_next=x+h*u`, even though an expression containing `A^-1` is undefined.
- Singular-safe update: `Ad=exp(hA)` and `Bd=integral_0^h exp(A*tau) B d tau` are valid for every finite square A. `A^-1(Ad-I)B` is an identity only when A is invertible. A block exponential of `[[A,B],[0,0]]*h` supplies Ad and Bd together without assuming A inverse; alternatively use a properly defined matrix phi function. Reassess cancellation and scaling in the actual implementation rather than using inverse notation as an algorithm.
- Prerequisites and boundaries: finite-dimensional constant A/B, declared column-state convention, specified input interpolation and initial state. These elementary corrections do not establish that every selective, input-dependent or learned SSM implements the same discretization. Recheck the relevant original model papers before making that broader claim.
- Evidence: the named source paragraphs were read on 11 September 2026. The defects follow by direct substitution and variation of constants; no destination runtime was executed. [MIT matrix-exponential and variation-of-parameters materials](https://ocw.mit.edu/courses/18-03sc-differential-equations-fall-2011/pages/unit-iv-first-order-systems/matrix-exponentials/) and [Lebl section 3.9](https://www.jirka.org/diffyqs/html/nonhomogsys_section.html) were inspected for the general linear solution. Executed author fixtures verify singular integration, direct-only output and nonzero initial memory. Production integration remains phase two.

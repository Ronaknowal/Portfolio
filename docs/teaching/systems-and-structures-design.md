## Per-investigation contracts

- Scheduler: predict which counter changes next; compare one/two-unit time slices and an I/O wait. Show the running process, saved instruction positions, ready queue and timeline together. The one-core deterministic model has zero switching overhead and is not a claim about Linux's current scheduler. Verify against independent hand-derived timelines and saved-state/ready-queue invariants; native examples establish actual process separation, not deterministic OS scheduling.
- Translation: hold the virtual address fixed while selecting the process; split it into page and offset, inspect the PTE and rights, then resolve a physical frame or explain a fault. Include resident, valid nonresident, unmapped and write-protected requests. Never equate TLB misses, page faults and disk reads. Validate arithmetic independently and factual mechanisms against primary OS sources.
- Copy-on-write: two processes initially point to one frame; compare a private write with a deliberately shared mapping. Show the fault/copy/remap/write sequence and both resulting values. Verify observable private/shared behavior in native Linux without claiming to measure exact physical frame sharing.
- Array movement: insert at front/middle/end or delete in the middle; compare spare/full storage, trace copied or shifted slots and count writes. Model geometric growth explicitly without asserting it is CPython's growth factor. Verify final sequences against Python lists and movement counts from independent index arithmetic.
- Unicode: select ordinary ASCII, composed/decomposed accented text or an emoji; inspect code points, UTF-8 bytes and NFC output. Highlight selected code point and its bytes. Verify against Python encoding/normalization. Explain that visual characters/graphemes are another layer; do not treat UTF-16 JS length as Python length.
- Hash buckets: choose lookup/update, key and bucket count; hash to a bucket, compare actual keys, and stop on equality or exhaustion. Include collisions, absent keys and replacement. Verify final map semantics against Python dict plus bounded comparison-count checks; no performance inference from browser timing.
- Linked reversal: retain node identities and explicit head/previous/current/saved-next references while changing arrows. Compare empty/singleton/three-node inputs and a premature-link-overwrite bug. Verify final traversal, acyclicity, preserved identities and orphan detection against independent Python/reference expectations.
- Bracket matching: trace each symbol, unmatched opening stack and output; include crossed pairs, early closer, unclosed opener and empty input. State the processed-prefix invariant and why one scan terminates. Test against an independent recursive recognizer for exhaustive short inputs. This is a bracket-only recognizer, not a programming-language parser.
- Circular queue: step enqueues/dequeues with capacity three/four, visible head/size/next insertion slot, physical wrap and FIFO output. A full enqueue is rejected rather than silently evicting work. Verify every state against collections.deque and empty/full/wrap invariants. Contrast bounded history eviction separately.

Core explanation remains visible; optional technical branches and solutions use progressive disclosure. Each example is complete and independently runnable. Each lesson has guided variation, a hint before the full independent solution and changed-input checks. Lab count follows these conceptual hurdles, not a site-wide quota.

## Work and evidence

Each topic receives a semantic subdirectory with a review record describing its concept-level coverage, existing strengths, actual gaps and corrections, research consulted, representations, preserved implementations and checks. Inspect the full lesson rather than imposing an identical new section or component on every page. An already adequate concept can remain unchanged with a reasoned source-located assessment.

The integration owner alone updates the central delivery ledger, publication metadata, generated inventory and shared instructions. Authors own disjoint topic/runtime files and their local records. Independent reviewers read the revised content and close specific findings. Browser checks are separately attributed to the person/agent that actually performed them. Completion is not inferred from a table, file existence, a build or a count of figures.

The baseline in ../evidence/concept-intuition-baseline.json records the original rows, current file identities, publication mappings and scoped module order before changes. Earlier uncommitted work and historical evidence are preserved. Source-only, browser, numerical and full completion remain distinguishable; consult the central ledger and each current topic record before continuing.

Full implementation is authorized. Topics are processed in bounded groups for writing and independent review, with per-topic source checkpoints so a session can resume without repeating completed work. Finish the actual review and integration before claiming a topic complete. No human learner trial, exhaustive mastery guarantee or new native experiment is implied by this review.

## Visual specification / actual checks

- `tied-risk-denominators`, after the two tie calculations: HTML bars all use 0–6.5. Repeated Breslow vs partially depleted Efron denominator, with formula/readout outside geometry. Fractions are an approximation, explicitly not a fabricated event ordering. CSS stacks arithmetic naturally.
- `aft-time-dilation`, after the AFT definition: reference exponential .1/day quartiles and doubled times on one 0–30 day axis. Matching markers are percentiles, not individual counterfactuals. Dashed connectors show what is mapped. SVG text stays separate from the timeline ticks; caption has complete numerical meaning.
- `competing-risk-denominators`, after Fine–Gray definition: constructed population masses .20/.30/.50, exact proportional segments, explicit text legend and denominator .20 versus .70. Layout can wrap denominator prose on phones. No observed dataset falsely attributed.
- Person-period table is an exact likelihood trace; it does not imply independent subjects. Greenwood and rate examples are direct arithmetic, recorded with parse/preservation evidence in `author-checks.json`.

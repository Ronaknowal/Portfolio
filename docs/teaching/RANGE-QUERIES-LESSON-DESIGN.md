## Teaching route and complete examples

1. **Choose a range contract.** Scan baseline versus static prefix sum; half-open `[l,r)` and empty identity. Show a changed point invalidating several prefix totals. Explain why minimum cannot be recovered by subtraction and why a range structure is useful only for the actual workload.
2. **Cache disjoint interval summaries.** Segment tree leaves follow original array order; internal nodes own contiguous ranges. Derive associativity and identity with sum/min/string-order examples before naming a monoid. Build with next-power-of-two padding, point assignment, canonical disjoint query cover, ordered left/right accumulators, and the two-boundary-per-level argument. Complete generic Python tree and exact sum/min/noncommutative demonstrations; merging strings is not constant-cost.
3. **Choose binary-sized prefix blocks.** Fenwick cells store `[i-lowbit(i),i)` in external zero-based coordinates, though internal indices start at one. Low-bit extraction and query subtraction remove one selected binary bit at a time; update addition visits precisely containing blocks. Complete linear build, add, prefix, range and point-set/delta reasoning. Explain sum/inverse scope rather than claiming every aggregate can use ordinary cancellation. Frequency-table/rank selection is a purposeful deeper application with nonnegative-prefix monotonicity stated.
4. **Change a whole interval.** Difference boundaries turn one range addition into two point deltas; derive offline reconstruction and online point query. Derive a two-Fenwick range-sum formula from how many times each difference contributes, rather than presenting a memorized identity. Its update/aggregate family is narrower than general lazy trees.
5. **Keep a correct answer before all descendants are current.** Lazy sum stores an already-updated parent and a pending map for children. On partial overlap, push before descending and pull afterward. Sum needs segment length for addition. A unified affine tag `x -> m*x+b` with `m` restricted to 0/1 represents set/add; compose the new action after the old. Show set-then-add versus add-then-set and empty/singleton boundaries. Complete Python class, independently verified direct-array sequences.
6. **Exploit a fixed array.** Sparse-table minima over power-of-two blocks, two overlapping blocks for an arbitrary nonempty interval, and idempotence. Explain why updates defeat the static preprocessing advantage and why sum would count overlap twice. Compare build, storage and operation costs under declared constant-time combine assumptions.
7. **Let a moving boundary retire candidates.** Fixed-window maximum: index deque, expiry versus newer-at-least-as-large domination, newest equal maximum policy and amortized pushes/pops. Then signed shortest-at-least: use prefix indices with increasing totals; front removal records the shortest useful ending for that start, and back removal discards a later-dominated start. Query before appending current prefix avoids an empty range; target positive in the teaching contract. Complete programs return witness identities/ranges and compare with brute force.
8. **Turn a DP scan into a query.** Compress known values by sorted unique rank without changing input order or treating rank gaps as distance. Derive weighted strictly increasing subsequence, exclusive-rank max query, max point update and parent recovery. Use duplicate values and negative weights to distinguish the needed summary from LIS tails. Link future persistent and geometric extensions with honest limits.
9. **Independent transfer.** Design before code: noncommutative fold/identity failure, lazy set/add order, subtree-to-contiguous-range mapping or a small rectangle-prefix extension, and deque tie/negative counterexamples. Explain acceptance cases and complete solutions. Curate official LeetCode tasks by taught operations and changed contracts, with no arbitrary count target.

The provisional anchor array is `[2,1,3,4,0,5,2,1]` (sum 18), with segment query `[1,7)` giving 15. Fenwick prefix 7 combines blocks `[6,7)`, `[4,6)`, `[0,4)` with sums 2,5,10. A point increment at external index 4 visits internal positions 5,6,8. Keep arrays/edit bounds small in the browser; full Python examples are not browser interpreters. Final read/practice estimates follow the actual material.

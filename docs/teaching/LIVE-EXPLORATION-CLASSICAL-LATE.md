## Runtime design and scientific boundaries

The shared LiveInvestigationState helper keys bounded calculations to actual inputs and an explicit comparison baseline. Publishing a result does not change its calculation key, avoiding a render/effect feedback loop. Reset changes an epoch so restoring already-identical input still recalculates. Valid results are published before paint; invalid drafts either suppress results in the bespoke labs or retain the last valid calculation with an explicit error/status in the shared labs. Comparison snapshots are bounded and never store a learner guess.

Gaussian Process controls pair sliders with exact numeric entry. Active Learning committee sliders redistribute the remaining class probabilities to preserve a valid vector. Existing trellises, posterior bands, contribution diagrams, acquisition geometry, score blocks, curves, bound terms and record timelines remain the primary learning representations.

Natural algorithm operations remain: acquiring an oracle label, stepping a propagation trace, advancing a search budget, applying a real architecture choice and opening a frozen assessment report. They do not require an expected answer. Rademacher validation selection stays live while assessment opens by a separate explicit inspection action; reset cannot make already-seen assessment data unseen. End-to-End uses the same distinction for its frozen test report. Unpurchased Bayesian measurements and unobserved oracle labels remain actual missing information.

No mathematical model/data module was changed by this worker. The manifest binds directly imported model/data files against the task baseline; unchanged scientific evidence is reused, not presented as a new numerical audit.

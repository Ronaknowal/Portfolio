## Learning contract and continuing examples

The beginner should be able to turn a short claim into defined objects and conditions, identify its proof obligations, produce a witness/counterexample, and read a small valid proof. Intermediate work includes equivalence classes and orders, image/preimage reasoning, induction and checking a finite specification. The optional end branch proves that no assignment from a set onto its entire power set can work; finite diagrams support the mechanism, while the general proof does the infinite work.

The opening invented roster is `U={Ada,Bo,Cam,Dee}`, with trained set `T={Ada,Bo}` and badge set `B={Bo,Cam}`. A claim that every trained person has a badge fails at Ada. This ties sets to implications without advertising a real deployed permission policy. A related job/reviewer board has jobs Scan/Label/Audit and reviewers Ada/Bo/Cam, with a diagonal starting assignment: every job has someone, but no reviewer covers every job. Number examples explicitly switch domains to integers or naturals; natural numbers here include zero.

## Representation contracts

**Membership figure, before set operations.** Show an element `2`, the singleton `{2}` and the container `A={1,{2}}`, with explicit arrow labels: `{2}∈A`, `2∉A`, `{2}⊄A`. Braces and nesting encode actual set membership; position has no numerical meaning. On phones stack the three statements while keeping the nested container visible. Separately explain `∅⊆A` for all sets and `∅∈A` only when included as an element. Check with nested immutable Python sets.

**Set regions.** Start with the four-person roster and overlapping training/badge memberships. Controls select a set operation and toggle each named person's membership. Diagram locations are determined by the four actual Boolean regions, with selected regions shaded and element names retained. Exact output roster and membership rule update together. All/empty presets, deterministic reset and keyboard buttons are required. This is a finite universe; complements are never implicitly global. The diagram does not encode set cardinalities by area.

**Truth-assignment investigation.** Start with premises `P→Q` and `Q`, proposed conclusion `P`. All four worlds remain visible; the model marks which satisfy all premises and gives a specific admitted world falsifying the conclusion. Switch to `P` or `¬Q` to see valid rules, or inconsistent premises to see no admitted worlds. Explain vacuous entailment and why it does not establish that the premises describe a real case. Truth and validity are separate. Inputs are named finite formulas rather than an unchecked expression evaluator.

**Quantifier witness board.** A 3×3 relation starts with one approved reviewer per job. Click a cell to add/remove the actual relationship; select `∀job∃reviewer` versus `∃reviewer∀job` and their duals/negations. Highlight independently chosen row witnesses or a whole successful column and concrete failures. Domain-size controls 0–3 visibly remove rows/columns, so vacuity and failed existence are inspectable. Keep the quantifier order in ordinary language beside notation. This finite exact model has no sampling error; it is not a claim about all infinite relations.

**Proof lanes and map figure.** Immediately beside the worked proof, labels distinguish currently assumed hypotheses from derived statements and mark the end of a local assumption. A separate square-map figure connects two distinct inputs to one output, with selected image/preimage sets on the appropriate side. These are static concrete correspondences, not decorative flowchart boxes. Narrow screens keep arrow direction and labels legible by stacking meaningful stages.

**Relation investigation.** Presets include congruence classes, a near-neighbor relation that fails transitivity, identity and an order. Editable pairs are a bounded 4- or 6-element relation with cell buttons and a selected failure witness. Property checks return a missing loop, reverse edge, transitivity shortcut or antisymmetry violation. Display equivalence classes only after all required axioms pass, otherwise explain why grouping would be unjustified. An order view uses actual covers only for a valid partial order. Reset and preset changes restore complete coherent state; edge arrows and omitted loops are explained.

**Order figure.** Divisibility on `{1,2,3,6}` is a diamond; on `{2,3,6}`, 2 and 3 are incomparable minimal elements. Covers alone are drawn upward with explicit text explaining that reflexive/transitive pairs remain in the relation. Exact pairs/covers are independently checked. No total ranking is inferred from horizontal position.

**Odd-square investigation.** A bounded stage `n` shows an `n×n` square plus the `2n+1` new tiles making `(n+1)²`. One corner belongs to only one counted border part. Move back/forward, inspect counts and reset. The formal proof states the base and the arbitrary step; the finite display never substitutes for that reasoning. No formula is inferred merely by fitting a few values.

**Diagonal subset investigation.** Four named inputs each map to an editable subset of the same universe. Construct `D={x:x∉f(x)}` by flipping the highlighted diagonal. Selecting a row shows the exact element where its proposed subset differs from D; changing other cells cannot repair its own diagonal mismatch. Explain finite candidate lists, then prove the arbitrary-set theorem using the same membership contradiction. Distinguish subsets, their elements and the function's codomain; a table is not an infinite data structure.

## Complete examples, practice and verification

Topic-owned Python examples will be standalone standard-library programs with setup before the first program, visible questions, exact inputs and actual stdout. Planned jobs are set operations/nested membership, implication countermodels, quantifier strategies/empty domains, function image/preimage, relation-property witnesses/classes, Hasse covers/extrema, induction's counted square border, diagonal construction, a finite-check counterexample and an integrated roster-policy audit. Independent practice will change objects or constraints: nested-set membership; a De Morgan identity with its universe; necessary/sufficient language; negating a mixed quantifier and describing witness dependency; repairing a false converse or illicit assumption; proving a changed set/preimage identity; constructing and proving an equivalence relation; distinguishing least from minimal under a changed order; a valid induction step and a failed step; diagonal membership contradiction; and the finite roster capstone.

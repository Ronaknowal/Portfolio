## Learning route and conceptual contracts

The anchor question is: **“Many curves fit these readings. What makes one curve a controlled, useful prediction?”** Start with observations on `[0,1]`, then revisit the same function-space geometry for interpolation, noisy fitting and integration. Required reasoning stays visible in the core. Longer proofs, integral spectra and approximations use clearly named optional branches after their local introductions.

1. **Functions can move, add and approach each other.** Show two curves and their sum before introducing the vector-space definition. Compare maximum error, integrated squared error and integrated squared slope. Define norm and inner-product rules, Cauchy–Schwarz, and the parallelogram identity with hand substitutions. A two-coordinate ℓ¹ counterexample shows that a norm need not come from an inner product. Define Cauchy and complete using error thresholds, then finite-support truncations of `(1,1/2,1/4,…)`: the tail has a calculable ℓ² norm, but the limit is not finitely supported. Explain Banach/Hilbert precisely. L² completeness may be stated as a theorem with an optional subsequence/Fatou proof; finite pictures are not its proof.
2. **What does “well-behaved measurement” mean?** Define a linear operator and a scalar-valued linear functional. Derive bounded iff continuous for linear maps, introduce the operator norm, and distinguish linearity from boundedness. Triangular spikes of height 1 and half-width ε centered inside the interval have L² norm squared `2ε/3` while evaluation stays 1. In L² classes evaluation is additionally not well-defined; these are two distinct objections. Define closed subspace/projection and show why an infimum may not be attained without closedness. Derive orthogonality and Pythagoras; make the Hilbert/Riesz proof accessible through the kernel of a nonzero continuous functional, with zero functional handled separately.
3. **Build an actual RKHS instead of naming one.** Define `H={f(t)=∫₀ᵗg(s)ds : g∈L²[0,1]}`. This supplies absolute continuity, the anchor `f(0)=0`, and the unique continuous representative; “an a.e. derivative exists” alone is insufficient. Its derivative map is an isometry onto L², so completeness follows. Derive `k_x(t)=min(x,t)` from `k_x′=1_[0,x]` and show `<f,k_x>=∫₀ˣg=f(x)`, `||k_x||=√x` and `|f(x)-f(z)|≤||f||√|x-z|`. The kernel is an evaluation instrument, not a density. Explain why the anchor removes the constant-function null direction of derivative energy.
4. **From a kernel to functions and features.** Define symmetric PSD for every finite list and coefficient vector. Derive the finite Gram norm; check a polynomial feature map and a valid structured-input feature map (e.g. short string bigram counts). Preserve the original mentions of polynomial/string/graph/domain kernels while explaining that an arbitrary graph similarity is not automatically PSD. Show the three-point invalid matrix below. Explain the finite kernel span, null coefficient directions and completion; the bounded evaluation bound ensures limit values are well-defined. State the general kernel/RKHS correspondence with its assumptions. Give an elementary real RBF expansion/feature argument before referring to infinite dimensions.
5. **Why only the observed locations remain.** Let `W=span{k_xi}`. Decompose `f=f_parallel+f_perp`; evaluation at the data sees only the first component, while squared norm adds. Give a complete altered-curve example with unchanged sample values and increased derivative energy. Prove the representer conclusion, conditioned on an existing minimizer: strict increase of the norm penalty forces every minimizer into W; nondecreasing penalties allow a span minimizer but can leave other minimizers. This theorem alone does not guarantee existence, uniqueness, convexity or generalization. Derive piecewise-linear minimal-energy interpolation by intervalwise Cauchy–Schwarz.
6. **Fit noisy observations and interpret the result.** Define the average-loss objective `(1/n)||f(X)-y||²+λ||f||²`, λ>0, and derive canonical coefficients `(K+nλI)α=y`. Do not cancel singular K in a coefficient gradient. Explain strict convexity in f, unique shifted-system solution, and possible other coefficients representing the same f when K is singular. Map the preserved original's sum-loss shift `.1` to average λ `.05` for n=2. Display its exact original code/output, then a stable NumPy implementation, prediction contributions, residuals, `αᵀKα` and the primal finite-feature identity. Duplicate locations and conflicting labels must be explicit. Explain an optional unpenalized intercept and its extra constraint rather than silently assuming all kernels contain a free constant.
7. **Choose a model without fooling the evaluation.** Build the old noisy-curve exercise into a complete seeded train/validation/test program with a linear ridge baseline. Explain the split, training-only feature scaling, held-fixed data and loss metric before the sweep. Show actual finite results; parameter extremes can underfit/localize for this dataset, not universally. Define generalization as performance on new draws under stated assumptions. Report dense Gram `O(n²)` storage and typical direct `O(n³)` factorization for fixed input dimension/kernel-cost convention. Compare a landmark feature construction, random features and matrix-free iterations by what they store/approximate. Include complete native approximate calculations with rank tolerance and fixed seeds; no illustrative speed curves named as benchmarks.
8. **Measure a whole distribution.** Starting from the same reproducing bound, construct the continuous expectation functional. Require measurability of the functions/integrand and `E√k(X,X)<∞`; explain the bounded functional bound and obtain its representer by Riesz. If using Hilbert-valued expectation notation, state strong measurability (the concrete continuous kernels on separable Euclidean domains satisfy the needed conditions). Derive the witness/unit-ball supremum and pair-sum formula with independent draws. A finite polynomial kernel can miss distinct laws with the same moments. State the scoped Gaussian characteristic theorem for every fixed positive bandwidth on Borel probability laws on R^d. Distinguish this from PSD validity, finite-sample power and universality; define the latter's target function class and topology rather than treating it as a synonym.
9. **Use the geometry beyond regression.** Work a kernel quadrature rule in the same anchored space. The integration representer is `m(t)=t−t²/2`, with norm squared `1/3`; derive the exact worst-case error as the norm of the residual representer. Nodes/weights are not automatically a probability distribution and need not integrate constants in a space that excludes constants. This is a deterministic function-class bound, not a confidence interval. Then connect to the GP posterior-mean identity and distinguish RKHS functions from Brownian paths. An optional spectral branch teaches bounded adjoints and compact diagonal inverse instability, then a conditioned Mercer expansion with positive eigenvalues, coefficient norm weights and a fully worked finite-rank kernel. Finish with changed practice and a bridge from norm-induced distance/continuity to the next Topology lesson.

**Proof boundaries:** core evaluation and representer results receive actual derivations. Mercer and Gaussian characteristic generality are labeled sourced theorems with stated hypotheses; their full spectral/Fourier machinery is an optional further study direction, not hidden work required to follow the calculations. Include sufficient conditions without implying necessity. Do not claim arbitrary RKHS norm is physical smoothness or that GP sample paths universally lie outside every finite-dimensional RKHS.

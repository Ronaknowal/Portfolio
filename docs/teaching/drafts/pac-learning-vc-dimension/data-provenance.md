# PAC/VC data and calculation provenance

Three evidence types are intentionally separate.

1. **Original mathematical constructions:** ordered threshold/interval patterns; triangle/square/collinear/interior point configurations; finite four-input target; binary-fraction sine construction; bound expressions and independent practice. These are not observed data or model benchmarks. pac-calculations.py generates their checked-results.json records. The finite-world occupancy probabilities and sine witnesses use exact Fraction arithmetic. LP feasibility is numerical, with signed-margin residual assertions; manuscript geometry supplies the class-wide proof.
2. **Constructed sampling experiment:** X~Uniform[0,1], Y=1 iff X in[.3,.7], smallest positive-sample interval, empty rule if no positives. NumPy default_rng(41),1000 independent samples at each n10/20/50/100/200 in that loop order. Each fitted rule's risk is analytic symmetric-difference length. Across-run failure counts are Monte Carlo results, not exact failure probabilities. Store counts/means/min/max/.05,.5,.95 quantiles and first20 risks per n, not a falsely complete sample histogram. The two-strip bound is separately derived. No finite experiment proves the theorem.
3. **Measured development curves:** UCI Banknote Authentication data, fixed nested training subsets and a shared development set. Source and transformations follow.

Banknote Authentication: Volker Lohweg(2012), [UCI record](https://archive.ics.uci.edu/dataset/267/banknote+authentication), DOI [10.24432/C55P57](https://doi.org/10.24432/C55P57), [CC BY4.0](https://creativecommons.org/licenses/by/4.0/). The original data has1372 rows, four continuous wavelet-derived image features and binary class code, without missing values. Retain source spelling `curtosis`; no unsupported genuine/forged class mapping is supplied. Attribute creator, source and license and disclose subset/split changes on the downloadable asset.

Evaluate each on its training prefix and fixed80 development rows. The program does **not evaluate the80 test rows** and makes no final model-selection/test claim.

Reusing a fixed development set and nested prefixes does not create independent replicates or justify uncertainty bands. This protocol differs from earlier semi-supervised/active-learning label budgets and metrics' two-feature threshold-selection experiment; cross-lesson curves are not controlled head-to-head comparisons.

## Material original inaccuracies addressed

- Historical/safety prose implied exact/minimum data requirements and regulatory certification. Sufficient bounds, statistical existence, efficient algorithms and operational evidence are now separated; no unsupported legal/regulatory claims remain.
- Original “probably” denied that the algorithm can fail, omitted internal randomness and mixed training-draw failure with predictions. Both randomness levels and event inequalities are explicit.
- Threshold explanation contradicted its coordinate ordering. Half-plane XOR argument omitted interior/degenerate configurations. Correct proofs and witnesses now cover each necessary case.
- Original displayed VC constants were not tied to a verified theorem and numerical plots disagreed with the formula. Use one explicit conservative convention throughout, retain raw values above1, state domain and log base. A valid but vacuous result differs from an inapplicable theorem.
- Original realizable/agnostic rates became exact100× requirements and agnostic excess bounds became absolute error promises. Both changes were incorrect. The manuscript keeps sufficient/class-relative guarantees and correct factor2/optimization error.
- Generic model-family capacity labels assigned RBF SVC “medium VC” and bounded it by one fit's support-vector count. Remove that inference; empirical learning curves cannot estimate the unrestricted family's VC dimension. Norm/margin restrictions need their own specified analysis.
- Old growth heatmap was numerically invented: intervals at n5 have16/32=.5, not.015. Sauer upper bounds do not assert every class attains the count. Fraction-of-all-patterns is not polynomial decay just because numerator is polynomial.
- Random half-plane attempts are one-sided evidence; failing to find a separator does not prove none exists. Current finite LP checks verify margin witnesses; geometry proves the universal statements.
- Original interval fallback chose a made-up positive region when no positives were sampled. New learner returns the empty positive region and exact risk equals target mass. Known-risk geometry removes unnecessary Monte Carlo test-error noise.
- A handful of draws with no bound violation did not verify a theorem, and more data need not improve each independently redrawn observed error. Repeated simulation counts remain estimates; null/contradictory cases are explicit.
- Old plots, arithmetic ratios and “always much looser” claims were not evidence. Calculated theorem curves, measured curves and exact enumerations have separate captions and receipts.
- Original neural-network VC, stability and PAC-Bayes claims were overgeneral and some complexity-class claims lacked a specified representation. State exact ReLU result only, qualify other tools, avoid promising generic tractability/tightest bounds or automatic SGD guarantees.
- Axis-aligned box proof falsely asserted the unused point lies in the extrema's convex hull; only bounding-box containment is necessary and always valid. Practice makes that distinction explicit.
- Original exercise selected the lowest accuracy while describing best-model optimism and proposed an unqualified Bonferroni/standard-deviation formula. New fixed-family exercise specifies correct event, sample size and protected selection.

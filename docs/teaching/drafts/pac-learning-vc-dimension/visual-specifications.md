# PAC/VC — figures and investigations

Research/write handoff only. No graphic, interaction, browser integration or phase-two verification is implemented. Three investigations serve three different mechanisms; the mathematical figures appear where their concepts are introduced. Programs/checked-results.json provide author-calculated reference values.

## Shared interaction contract

Start every investigation with an unsolved question and **no prediction selected**. Prediction fields are explicit choices/numbers and a short explanation; Commit binds them to a fingerprint of all current entities, labels/coordinates, class, target, proposed change, sample/seed, tolerance and fixture version. Hide destination results until Reveal. Any dependent edit invalidates the prediction/result. Changing hover/focus only does not. Reset restores the named fixture and clears attempt/result/history. A preset is an entry point, not the entire exercise: learners must edit actual inputs and constraints. Provide meaningful exact contrasting and null cases below.

Use text, position, shape/pattern and labels rather than color alone. Every figure has a concise caption and readable source table. Editable points have keyboard/numeric alternatives; no precise dragging requirement. Focus remains on the edited entity or announced result heading. A polite live region announces the result after reveal, not every drag movement. Disable motion under reduced-motion preference. On narrow screens stack input, illustration and explanation; preserve tap targets and avoid squeezed math/axes. All hints/solutions remain closed initially.

Small exact operations can run synchronously; do not import a general optimizer or all curriculum data into the browser for these cases. Load the optional measured curve assets only when needed. No remote training, autoplay or background polling. Distinguish exact combinatorial/rational quantities, numerical feasibility checks, Monte Carlo estimates and measured development results in captions. A supplied bound is a computed theorem expression, not a benchmark.

Decimal user coordinates use a bounded precision (at most three fractional digits); rationalize those decimal inputs for endpoint/equality comparisons where practical. Full internal precision for numerical quantities; display fractions and counts first, six decimals where useful. For the seeded continuous simulation, equality with epsilon has probability zero; do not interpret floating-point roundoff at a hand-constructed .1 boundary as a conceptual theorem failure.

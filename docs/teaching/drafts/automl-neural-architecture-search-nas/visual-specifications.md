## Shared investigation contract

Every investigation starts with inputs and a question, **no selected prediction, and no revealed computed answer**. The learner edits meaningful entities, records a prediction, and explicitly reveals the result. A result is bound to the full active input tuple, source revision and question. Any meaningful edit invalidates current feedback and requires a fresh prediction. Reset restores initial inputs and clears prediction/result. A previous attempt may remain in an explicitly historical collapsed area, never as the answer to edited inputs.

Questions ask for an observable choice, count, ordering, numerical result, or directional change. Store the response plus optional reasoning. Feedback compares the prediction with the computed outcome and explains the relevant mechanism. Do not silently preselect the correct option, auto-update a prediction as controls move, or treat a preset click as learner reasoning. Presets can provide starting cases but do not replace editable configurations, curve values, operation inputs, or candidate entities.

The default figure before reveal must not answer its own task through a visible derived count, highlighted winner, displayed gradient, or frontier classification. Raw input data remain visible. Formula definitions supplied by the lesson are allowed. Use semantic buttons and labeled controls, visible keyboard focus, and field-specific error messages. Draggable objects also have numeric inputs or keyboard reorder controls. Color must be redundant with line style, shape, operation name, and text status. Charts expose an ordered data table and short interpretation. Mathematical zero and undefined quantities are different states; do not substitute epsilon where it changes the mathematical example.

On narrow viewports, stack explanation → controls → task → visualization → accessible table. Keep labels legible and use a locally scrollable table where its comparison genuinely requires columns. A tree can become nested disclosure rows; a horizontal resource ladder can become vertical rung panels; an operation graph can become an ordered flow list. ## F4 — Differentiate the function that was actually defined

**Anchor:** §7, scalar bilevel example. **Mechanism:** direct, one-step, and exact-inner derivatives differ because their weight dependencies differ.

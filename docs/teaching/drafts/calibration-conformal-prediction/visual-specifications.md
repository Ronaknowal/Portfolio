Content-only preparation. No diagrams, React components, browser labs, download routes or phase-two verification are implemented. Repeating a generic parameter slider would obscure these different mechanisms.

## Shared behavior and evidence contract

Every investigation starts with **prediction unset**, an editable problem, and destination results hidden. Commit records choices/numbers and an explanation against all active inputs, entity IDs, score definition, method, target alpha, proposed edit and fixture version. Reveal compares the committed prediction with a calculation, explaining why it agrees or disagrees. Any dependent edit invalidates the attempt/results; hover, focus and scrolling do not. Reset restores the named unsolved fixture and clears attempts/history/results and any pending calculation.

Controls operate on meaningful entities: actual observations, labels, block weights, score cards, scale estimates and query coordinates. Presets are entry points rather than the only allowed action. Use textual labels, counts and position in addition to color. All pointer edits have keyboard/numeric equivalents. Announce revealed results politely, preserve focus, use reduced motion, and keep hints/solutions closed. Stack inputs, view and interpretation on narrow screens; use scrollable real tables where appropriate, not compressed illegible cells. Figures include accessible source tables and captions naming measured, constructed or exact data.

Bound the small operations below. Do not load sklearn, an optimizer, all model assets or an entire module to render these labs. PAV and sorting can be small local calculations; measured experiment views replay topic-owned data on demand. If a live fitting extension is desirable later, it needs independently verified computation, limits and responsive cancellation; it is not required to satisfy these contracts. No remote training, autoplay, polling or background simulation.

Use fractions/exact decimal comparisons for editable constructed values where practical. Show counts before rounded percentages. For conformal prediction, maintain the same score function and weak inequality throughout; the stored floating_boundary fixture proves that naive algebraic rearrangement can lose ties. Do not fix arbitrary substantive differences with a large epsilon tolerance. Stored full-precision data remain the numeric authority; no invented benchmark curves.

**Editable state:** 4–30 cards, each probability in[0,1] with up to3 decimals and binary outcome; 1–6 bins with strictly increasing internal edges. p=0 and1 included; internal boundaries go right. Each card has stable ID. Reordering changes presentation but not membership or results; editing probability/outcome/edge/count changes the calculation and invalidates prediction. The constructed evidence can be fully visible while the aggregate destination is hidden; no need to hide the problem inputs.

**Calculation:** For each bin compute count, positive sum, mean probability and fraction positive; ECE=sum n_b/n*abs(meanY-meanP). Empty bins have no fraction/mean, zero weight. Optional Brier and AUC are computed from the same arrays with their definitions; AUC undefined with one outcome class. Distinguish this class1 ECE from any top-confidence mode.

**Checked contrast:** Two-bin ECE=.2, points(.2,.4),(.8,.6). Merge all into one bin→point(.5,.5), ECE0. Keep two bins and replace probabilities with .4/.6→ECE0, Brier .24 versus .28, AUC .6 unchanged. This is an in-sample constructed map, not a validated calibrator. **Null:** any row permutation preserves every aggregate. Exact boundary fixture p[0,.5,1],y[0,1,1] has counts1/2, no lostp1 observation.

**Feedback:** Show the two cancellation arrows when merging bins; ask which information disappeared. Grade a probability edit on its actual new bin membership rather than assuming only one dot moves.

## Accuracy findings resolved in the manuscript

1. The old assertion that all binary metrics follow from one confusion matrix excludes ranking/probability metrics. Four input families now establish the boundary.
2. A low prevalence does not make AP .30 “near random” when the constant-score baseline is .01. Baselines are tied to the actual population/convention; finite random rankings need not equal prevalence exactly.
3. Davis–Goadrich's curve-dominance result does not imply AUC and AP always rank models alike. The checked counterexample explicitly disagrees.
4. The original curve routines and outputs mishandled equal-score groups and PR direction/AP integration; replace with grouped thresholds, increasing recall and an independent pairwise AUC cross-check. A no-alert endpoint is above the maximum, not automatically threshold1.
5. No-alert precision is undefined; epsilon denominators fabricated a numeric answer. Raw undefinedness is retained separately from a documented API aggregation convention.
6. Lowering threshold preserves recall monotonicity on fixed outcomes but not precision monotonicity; the .5→.3 example increases both. Fβ's β² factor is not automatically an operational error-cost ratio.
7. AUC.5 does not prove equal score distributions. Ties receive half credit. ROC invariance under prevalence change assumes fixed class-conditional behavior, not arbitrary population shift.
8. Log loss is not a function of threshold for fixed probabilities. Brier/log loss assess overall probability forecast quality, not calibration alone. Binary versus multiclass Brier normalization is made explicit.
9. The old example independently standardized test data. The real experiment uses a training-fitted pipeline for every split. It preserves the test-cost failure of development tuning.
10. Test R² uses the evaluation target mean in SST. A training-mean baseline may have negative R². Negative R² does not diagnose overfitting by itself. Constant targets require an explicit convention.
11. MAE is less sensitive to large residuals, not immune; median error can hide bad minority outcomes. MAPE zero dropping/sMAPE do not universally solve zero denominators. Mean/median/quantile forecasts need matching losses.
12. Old multiclass weighted calculations and universal averaging claims were wrong. New matrix arithmetic is checked; micro=accuracy is limited to exhaustive single-label tasks. Weighted F1 need not lie between macro and micro.
13. Original exponential-gain NDCG did not match the raw-grade sklearn call or claimed output. Both conventions are now calculated and explained; candidate set and tie rules are explicit.
14. Remove fabricated runtime/error guarantees and smooth curves. ROC/AP need global order or a declared approximation; fixed confusion counts stream exactly. Batch F1 averaging is exposed with unequal batches giving .75 versus pooled2/3.
15. Replace misleading false-alert-per-true-positive and medical deployment prescriptions with a neutral inspection example and explicit operational assumptions. Correct figures are derived or measured with a visible provenance distinction.

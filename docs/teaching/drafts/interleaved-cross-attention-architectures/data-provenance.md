# Cross-attention study: data and evidence provenance

Prepared2026-09-13. Dataset creators E.Alpaydin and C.Kaynak,1998: [UCI Optical Recognition of Handwritten Digits](https://archive.ics.uci.edu/dataset/80/optical+recognition+of+handwritten+digits), [DOI10.24432/C50P49](https://doi.org/10.24432/C50P49), CC BY4.0 (license inspected at the primary UCI page). This is not MNIST. Attribution and subset transformation must accompany distributed data.

digits-400.csv is an unchanged copy of the first40 occurrences of every digit in sklearn.load_digits, from the earlier convolution packet. Source IDs are original one-based sklearn rows. The sklearn1797-row dataset derives from the historical UCI test partition; using a classroom split here is not official UCI evaluation. Fields pixel_0..pixel_63 are row-major8×8 block counts0..16; digit is0..9. Known-bound division by16 is not a fitted transformation. Source CSV SHA-256 a5b50ff0418e2b470140153a399c9200b2bba68468232507fd393ba89c4fc672. Actual400 source IDs and all64-feature signatures are unique; repeated writers may still occur and writer IDs are unavailable.

The author constructs two question templates per image: digit recognition(label0..9) and parity(label10=even,11=odd). These are synthetic question forms over real images/annotations, not a natural-language VQA dataset. Split images before generating questions using NumPy default_rng912 separately within each digit:24 fit,8 development,8 assessment per class;240/80/80 images,480/160/160 question rows. Full source-ID assignments live in calculated-inputs.json. This subset is shared by earlier teaching examples and cannot support untouched cross-lesson benchmark claims.

cross-attention-study.py contains the complete data loading, three from-scratch classifiers, nine fits, all evaluation and exact fixtures. Python3.12.14, NumPy2.3.5, torch2.14.0+cpu, one torch CPU thread; shared environment read-only, no installs or model downloads. Seeds11/29/47; fixed160epochs, batch64, AdamW.003, weight decay.01; no dropout, data augmentation, checkpoint selection or held-out hyperparameter search. All nine fixed fits are shown. Parameters and fitting/development loss at actual epochs1/10/40/80/160 are retained.

Models: flat64-pixel+24-query MLP88→48→12; cross classifier16patches×4values→24channels plus16 learned positions,3head cross read, residual LayerNorm24/MLP24→48→24 and12-way head; gated adds scalar tanh gate initialized zero only on cross-attention output. All parameters train from scratch. Different capacity/initializations are not a matched-compute or pretrained-backbone ablation.

Assessment outputs include digit/parity correct counts, two image perturbations, and selected actual per-head maps. A first author run exposed a weak diagnostic: a one-image cyclic shift of label-grouped rows preserves most labels. The corrected final program retains that weak control explicitly and adds seeded5129 image-group shuffling, with exact semantic match counts. It reruns the affected study because earlier final weights were not retained. No model/hyperparameter changed in response to assessment scores; the control repair and all retained outcomes are disclosed. Future tuning still requires fresh evaluation data.

Only saved source/query/head combinations have trained attention maps. Full model weights are not retained; arbitrary browser neural edits are not supported by this packet. Maps are row-normalized mixing weights over actual2×2 patches, not ground-truth explanations. Complete numerical results and current code are required phase-two inputs, not scratch.

The NumPy fixtures are constructed exact arithmetic with floating-point evaluation: rectangular softmax, masks, masked-value null and paired permutation. Scalar gate and cache arithmetic are independently transparent in manuscript/specifications. They are not observations about a production model. No inherited hand-entered training/accuracy/latency curve or unlabeled invented heatmap is retained as measured evidence.

- Original1372 rows/four continuous image-wavelet features/no missing values. Columns variance, skewness, `curtosis` (source spelling), entropy, and source class code. No claim about which numeric class means genuine or forged. These are image-derived measurements, not scans of financial instruments available to the learner.
- Subset: NumPy `default_rng(23).permutation(1372)[:480]`, preserving that permutation order; append one-based original `source_row` and explicit split. First320 pool, next80 development, final80 test. CSV SHA256 `d28fa993ed459d2f706816395475af08eebd2f394be67f2ad42dd9b511fc6b5a`. This is the same subset as the preceding semi-supervised packet, intentionally copied to keep each future lesson's download self-contained. It is a required content asset, not an abandoned duplicate.
- Pool feature scaling fits only raw320 pool inputs, without labels, and transforms every split. All four strategies share this preprocessing. Each run starts with three pool labels per class, chosen using seeds7,19,31,43,59. This oracle-balanced initialization is explicitly assumed. It differs from the semi-supervised lesson's single first-three-per-class seed set.
- Within each run, random/entropy/committee/farthest receive the same initial six rows and30-query budget. No unknown pool label is used to choose a query. The implementation simulation possesses labels for the oracle; accessing `truth[row]` occurs only after selecting that eligible row. Initial class balancing is the disclosed additional use of pool truth before queries.
- Development labels compare four fixed strategies at final budget; no adaptive search or stopping on final test. Highest mean final dev correct wins; insertion-order ties prioritize random, entropy, committee, farthest. Only selected entropy models evaluate the final80 test rows. No dev refit. Training labels on curve =6+queries; development/test annotations are separate costs.
- `banknote-active-learning.py` is the complete executable learner program. Python3.12.14, NumPy2.3.5, scikit-learn1.9.1, SciPy1.18.1 author runtime. It was executed2026-09-12; output trajectories exactly matched `checked-results.json.banknotes`. The one duplicate run-output JSON was verified equal and removed; the retained checked record is the durable evidence. Running the learner program creates `active-learning-results.json` in its own directory.
- Every benchmark curve is measured output from those local executions. Repeat spread describes starting-label/randomness effects on the same dataset, not independent test-sample confidence intervals. Final entropy dev counts[79,79,79,80,79]/80; test counts[79,79,79,80,79]/80. Matching counts do not imply matching row sets. Original source rows in all three splits are disjoint.

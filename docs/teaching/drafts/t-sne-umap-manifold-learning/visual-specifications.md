## Shared contracts without a shared visual template

- Keep observation identity across every view. Use A…G on constructed geometry and the CSV's `source_row` on digits. Digit class is an optional inspection overlay and is never an embedding coordinate or numeric fit feature.
- Figures label their evidence category: exact constructed calculation, native fitted coordinates, or algorithm diagram. No wall-clock benchmarks are supplied. Units are input coordinate units, normalized pixel distance, probability, membership, rank or arbitrary map units as appropriate.
- Quantitative plots use numeric axes and a text/data equivalent. Draw scatter points without connecting unrelated samples. Map axes must have equal geometric scale within each map; scale and translation across different methods need not agree. Label “map coordinates” and do not compare their raw radii.
- Every investigation has **draft inputs**, **active inputs**, and an **unset prediction**. Choose/edit a proposed change, record a prediction, then press an explicit apply/check action. The saved prediction contains a deterministic key of the complete candidate input: data version, observation IDs, algorithm settings, question kind and candidate values. Edits invalidate it visibly. Never carry a previous prediction across a changed query, k, metric, fixture or map setting.
- Prediction options start with no selected answer; no default is silently submitted. Commit freezes the proposed inputs until applied or edited. Result feedback shows prediction, observed exact/rounded value, comparison and one causal explanation; it does not grade free-text explanations by keyword. An “Explore without scoring” path may be available with the prediction explicitly unrecorded.
- Reset returns the useful starting example and clears predictions/results. Undo restores the prior active input and marks the prior answer as history, not the prediction for new inputs. Invalid inputs preserve the last valid result, show an inline reason, and cannot be committed. Updates announce concise results through a polite live region; never announce every intermediate slider tick.
- Keyboard controls and numeric entry are complete alternatives to pointer dragging. Labels cannot depend on color, hover or animation. Reduced-motion/manual steps must reveal the same state. Retained/input-only/map-only edges use text badges plus different patterns.
- At 360 CSS px and 200% zoom, stack geometry before the local table and keep prediction/apply/results together. Never shrink a full-width SVG's text with a huge viewBox. Prefer HTML labels and compact independently sized panels. Full desktop width should not balloon labels. Keep a maximum readable figure width, while the digit map can use available width.
- Closed hint and solution disclosures are separate from the attempt prompt, including standalone written practice. Preserve headings, math and code within disclosures. Do not preload an answer into a prediction field.

## Shared implementation contract

Use topic-owned figures, model functions and lab files named for their mechanism. Load this topic's data and models only when its lesson/investigation needs them. Saved models total twelve 650-parameter arrays plus state; a selected model suffices for the image investigation. Do not fetch all other lesson data, train 24 models in the browser or eagerly load a scientific runtime. Browser calculations use ordinary double precision and bounded arrays; preserve full-precision inputs and round only labels. Complete runnable Python downloads are teaching artifacts, not browser dependencies.

Each investigation starts with **unset predictions** and a fresh problem different from the adjacent worked example. A learner edits an actual input entity, commits a prediction, then computes. Tie feedback to the input revision and predicted update; any input/model/seed/step/mode edit invalidates prior grading. Step-back may show a prior committed state but must not silently grade a newly changed problem. Reset restores all inputs, model state, mode, predictions and outputs. Hint and solution disclosures start closed. Show the actual calculation and diagnose a misconception rather than only marking correct/incorrect.

Provide keyboard-editable numeric inputs alongside graphical controls, visible focus, readable labels, and text/table equivalents for every diagram. Color is redundant with signs, labels, line styles and selected-cell borders. Narrow layouts stack mechanism stages while preserving arrow/order meaning; matrices may scroll within a labeled region, never the entire article. Announce completed calculations once; avoid screen-reader announcements for every pixel hover. Respect reduced motion. No autoplay, hidden grading threshold, unlabeled log axis or contrived animation is required.

Validate finite inputs and declared ranges before computing. If an exploratory calculation becomes nonfinite, stop at that step, retain the last finite state and explain the numerical event; do not replace divergence with a reassuring capped trace. Use tolerances for numeric predictions (absolute 1e-6 or relative 1e-5), and exact semantic comparisons for sign/order/mode choices. Browser parity and accessibility remain phase-two work.

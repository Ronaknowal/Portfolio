# Optimizer experiment and calculation provenance

Prepared and executed 13 September 2026 for content research/writing. This is a bounded classroom study of update rules, not an LLM or hardware benchmark. No runtime lesson was published.

## Declaration before fitting and actual scope

The declared comparison fixes a650-parameter65×10 linear softmax model, mean cross-entropy, batch64 sampled with replacement,400 updates, zero weight decay, no augmentation or early stopping. Initial weights use a normal distribution of standard deviation.01 with seeds11/29. At each seed all methods share initialization and batch RNG700+seed. Sophia pseudolabel sampling uses separate RNG1700+seed so it cannot perturb the shared batch sequence.

There are six methods, two candidate scales and two seeds: **24 actual fits**,9,600 optimizer updates. AdamW constant/cosine/Schedule-Free scales[.01,.03]; Lion[.003,.01]; Sophia[.01,.03]; Prodigy multipliers[.3,1]. The candidate grids, seeds and400-update endpoint were specified before fitting. Scale selection uses the mean final **validation** loss across both seeds, separately per method. No assessment-based selection or result-dependent retry occurred. All candidate histories remain, including poor validation results and grid-boundary selections. Two candidate scales do not amount to comprehensive tuning.

Rules are fully given in `optimizer_rules.py` and the manuscript. AdamW uses betas.9/.999,epsilon1e−8 and ordinary bias correction. Cosine AdamW warms over20 updates then decays to zero at400. Lion uses old-history blend.9 and stored-history.99. Sophia uses momentum.965, curvatureEMA.99,rho.04,epsilon maximum1e−12, refreshes1,11,…,391 with B64 times the independently sampled mean gradient squared. Four Sophia fits make40 extra gradient evaluations each:160 refresh gradients in addition to the ordinary training gradients. No Hessian matrix is constructed.

Prodigy implements paper Algorithm4 with scaled moments, initial d1e−6,no optional bias correction and no weight decay; current package defaults are not claimed identical. Schedule-Free is the paper's base AdamW-like rule with beta.9,second moment.999,epsilon1e−8,20-step warmup then constant rate, squared-rate averaging, gradients at y and evaluation at x. Its readable state storage differs from optimized package storage. Current external optimizers were read, not installed or executed in this study.

All operations use NumPy float64. Environment: Python3.12.14, NumPy2.3.5; independent AdamW comparison uses PyTorch2.14.0+cpu with one thread. There is no GPU measurement, throughput result or timing comparison. These fits isolate meaningful update behavior in a small real problem; they cannot establish large-model superiority, formal convergence or equal tuning effort.

## Calculated examples versus measured fits

One-dimensional bowls, gradient perturbation sequences,2×2 Hessians and70B memory allocations are explicitly declared mathematical/hypothetical inputs. They are not training benchmarks. Native AdamW parity on four unequal gradients at fixed nonzero decay is exactly0 maximum error in this environment. Late-impulse ratio2.5145667 demonstrates the lack of a general unit bound. The Sophia batch expectation is checked by independent enumeration against its analytic curvature; Hutchinson expectation is checked across all four probes. Prodigy moments are checked against expanded weighted sums, beyond repeating the recurrence. Fresh-target traces retain overshoots and zero-history stationary nulls. Schedule-Free stores worked/fresh/beta0/beta1/stationary traces and exact warmup weights. An independent SVD checks the ideal polar example; it does not execute Muon.

The real pixel examples use selected seed11 snapshots and validation source312(fresh) /277(worked). Pixel28 is changed from raw0 to16. Every score/probability/gradient/update uses that actual modified array. Labels can change the diagnostic gradient but not the preceding inference distribution. The Sophia **diagnostic** uses an exact expected-label diagonal for a linear model, distinct from the stochastic estimator used during fitting. Cosine update401 retains zero rate and exactly unchanged parameters/probabilities; momentum may still change. Snapshot edits are temporary and never overwrite fit/assessment records. One update's probability change makes no generalization claim.

The final author check recalculates metrics from stored full weights, validates selection from all candidate validation records, checks disjoint feature/identity roles, verifies finite JSON state, and checks changed practice arithmetic. Full browser behavior, independent phase-two review and production integrations are deferred. Source-bound packet hashes belong in the central ledger; do not treat a script's existence as evidence it ran.

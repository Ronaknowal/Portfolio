# Hyena: visual and investigation handoff

Content-first specification, 13 September 2026. No browser figures or investigations are implemented. Read the complete manuscript and the retained programs/results before building. Stable owner: `hyena-long-convolution-models`. These representations differ deliberately: echo alignment, matrix factorization, a filter coordinate ruler, editable DNA and a streaming state machine.

## Common interaction and accessibility contract

The reader must be able to understand the static mechanism without running a lab. Place every figure at its manuscript marker. Preserve the explicit first-pass route and optional deeper branches. Labels use the lesson's notation; introduce FIR, lag, mode and conditional coefficient before using shorthand controls.

All four investigations start with a fresh input distinct from the worked example. Show editable inputs and the question before any computed answer. Require an initially **unset** prediction and a short optional rationale. Predictions are stored with a canonical input/configuration signature and result revision. Editing any numerical/entity/configuration input invalidates the prediction and previous result; label the old result “For previous inputs” or hide it. Changing only the selected display cell does not invalidate. “Run experiment” records the prediction and evaluates the current inputs. A user can revise a prediction only before the next run. Never preselect the scientifically correct answer.

Provide exact original/fresh reset, which clears prediction, rationale, results and selected comparison; no silent restoration of an old answer. A named contrast or null preset is an input change and needs a new prediction. Feedback first shows what happened and a relevant numerical contribution, then invites the learner to reconcile it with the prediction. Do not grade an unconstrained open experiment against a canned result or claim a wrong prediction is a failed learner.

Use labeled native controls, keyboard selection and non-color signs/patterns. Hover detail is also available by focus/click. Each chart has an adjacent numerical table and a concise text explanation. Changes announce one short completion message through a polite live region, never every matrix cell. No drag-only inputs. A numeric editor accompanies every draggable stem/base selection. Motion is optional and respects reduced motion. No autoplay. Keep focus on the invoked control after a calculation.

At widths around 360px, place controls above the result and stack comparison panels. Matrices and sequences can use an explicitly labeled local scrolling region with sticky headers; never overflow the entire page. A selected-position card avoids shrinking all 60 bases or all matrix labels below readable sizes. Separate high contrast signed positive/negative/zero encoding from class colors. Equations and values remain selectable text. Allow rounding for display but calculate with full precision; show units as sequence positions and dimensionless values, or class probability as appropriate.

All teaching inputs are finite. Validate malformed numbers inline without throwing the whole reader. Bounds below limit investigation work, not the mathematical method. Runtime code must be topic-owned, lazy-loaded when needed and separated from manuscript assets. Do not import all papers, data or architecture models in the navigation bundle. Browser training is unnecessary: the real-data lab uses retained fixed weights, with direct bounded causal convolution as an acceptable independent implementation. Load only the chosen model's compact weights and the required selected records. Keep native training programs as downloads.

## HA — Find the future leak

**Placement/question:** immediately after the complete causal FFT program. Can an edit to a future input affect an earlier output, and what does padding change?

**Inputs:** editable signal length 2–12, values −8…8; editable filter length 1–12, coefficients −4…4; direct/padded/circular mode; selected output index; impulse and identity presets. Fresh signal `[2,-1,3,0,1]`, filter `[.5,1,-.25]`. Do not show its result before prediction. Prediction choices describe a range of output positions affected by a selected edit, with “other range” numeric fields; an additional sign prediction for the selected output is optional.

**Calculation:** direct formula from manuscript. For valid FFT use next power of two ≥ L+K−1, crop the first L outputs. Circular demonstration uses size L and restricts kernel length≤L, or disable circular when K>L with a concise reason; never silently trim a longer filter. Show actual P and padded lengths. A JavaScript direct circular sum can be the oracle; if using a browser FFT, separately verify its normalization.

**Checked contrasting fixtures:** fresh correct output `[1,1.5,0,3.25,−.25]`; circular `[2,1.25,0,3.25,−.25]`. Last input 1→5 preserves the first 4 correct outputs and gives final 1.75; circular first 2 become 6, .25. Input remains within bounds. Worked values are separate from these fresh values.

**Nulls:** identity filter [1] makes direct, padded and circular equal; all-zero signal produces zeros; same-value edit changes nothing. A chosen output can agree even when another leaks: fresh circular output 2 matches 0. Feedback must report the full checked prefix, not certify causality from that single match. Arbitrary-input “causal” feedback derives dependency indexes, not an absolute fixed threshold alone.

**Display:** aligned input/filter/output stems, wrap path, exact selected-output contribution table; mode names include “intentionally circular.” Readable signed values and finite errors. Direct vs FFT numeric error labeled arithmetic difference. Bound work to 12×12 direct products. Reset to fresh inputs and unset prediction.

**Phase-two verification:** independent direct/circular index reference across length/zero/impulse/odd-length cases; FFT outputs against exact sums; the two edited prefixes; invalid-input recovery, keyboard editing, mobile labels and input-signature invalidation. No training or hardware speed claim.

## HB — Build a selective route

**Placement and question:** after the hierarchy explanation. What changes when a sender is opened, a receiver is suppressed, or an intermediate path is added?

**Inputs:** length 4 by default, optionally 2–8. Independently editable v, k and q entries lie in −4…4; kernel entries lie in −2…2. The fresh vectors are `gates_fresh` in the mechanism results. An optional preceding filter phi starts at [1,−.5,0,0] and is independently editable within the same coefficient bounds. Switching between the single-filter sandwich and the two-filter hierarchy explicitly changes the operator. Selecting a matrix cell only changes the inspection view. Before running, record which output positions the proposed gate edit will change; allow an optional numerical output guess.

**Calculation:** H = Dq T_h Dk, y = Hv; the optional hierarchy uses H = Dq T_h Dk T_phi. Compute the signed matrix, input contributions and row sums. Changing only k2 from 0 to 1 changes fresh output [1,.625,1.5,−1.5] to [1,.625,7.5,−2.25]. The optional hierarchy gives [1,1.125,2,−.5] for the original fresh gates. All these fixtures are actually evaluated by `convolution_mechanisms.py`.

**Nulls:** zero values give zero output. Setting every q and k to one recovers ordinary convolution in the single-filter mode. Setting q_t to zero erases that row of this mixing path. Editing a value at j>t cannot affect output t when all gate inputs are held fixed. State that condition: in a complete neural block, editing the original input can also change other gates. This investigation isolates the operator; it is not the DNA classifier.

**Display and feedback:** show the source strip, transmitted values k×v, signed matrix, selected-cell factorization and output ledger. Adding phi introduces an intermediate-position column rather than hiding the extra operation. Highlight exactly the coefficients and output positions that changed after running. Feedback compares the stored prediction with the result and asks which factor explains it. Do not call coefficients probabilities or the full network Jacobian. Keep zero at the center of a labeled diverging scale that includes all current values.

**Accessibility, reset and limits:** every meaningful entry has a keyboard-operable numeric editor. A locally scrollable matrix and selected-row card replace unreadably small cells on narrow screens. Apply all common prediction, invalidation and reset rules. The bounded maximum is eight positions; even separately summing intermediate paths is inexpensive. No large model is needed.

**Phase-two checks:** compare separately indexed single-filter and two-filter sums against matrix products; check upper-triangle zeros, signs, gate edits and nulls; inspect prediction signatures, narrow table headers and focus. Verify the distinction between coefficients and weighted input contributions.

## HC — Which context changes this model’s answer?

**Placement and question:** after the worked DNA edit. Does changing a chosen part of the sequence change this fixed classifier’s leading class? Can the learner distinguish model sensitivity from a biological conclusion?

**Inputs:** start with validation source row 4, `sequence_fixtures[1]`, rather than worked source row 3. A 60-character editor accepts A,C,G,T,D,N,R,S; strip whitespace and normalize case. Explain invalid characters or length inline. Provide independently labeled base selectors plus a selected-span fill tool. Display both array indices and the relative-position labels. The default model is gated seed 29. Optional comparisons load the saved linear-29, ungated-29 or gated-71 fits. Further controls retain the full learned filter or only lags 0–4 and enable or disable the mixing gates. All models stay fixed: never launch browser training. Editing data, model or ablation invalidates the prediction and result; selecting a base or channel for inspection does not.

**Prediction:** an initially unset leading-class choice EI/IE/N for the edited sequence, or an increase/decrease/no-change prediction for its original-class probability. The learner chooses which hypothesis to record. Keep the observed label beside the original sample only. Compare original and edited logits and class probabilities without inventing an edited biological label.

**Exact model contract:** consume `SpliceReader`, `SequenceBlock` and `ImplicitFilter` in `splice_models.py`, and the complete `splice-fits.npz` arrays. Alphabet order is ACGTDNRS; class order is EI,IE,N. There are 16-dimensional embeddings, two residual blocks and a classifier at the final position. Preserve LayerNorm epsilon 1e−5, exact GELU (erf, the PyTorch default), sine filter activation, softplus decay, learned skip coefficients and all biases. PyTorch Conv1d computes cross-correlation; padding 2 and cropping the first L positions make the kernel-3 preprocessing causal. Preserve that orientation. Fixed lag coordinates are r/59, with nine position features. Buffers are part of the saved state. A direct causal convolution is acceptable in the browser if verified against native logits; a preset lookup is not an implementation of arbitrary sequence edits.

**Checked contrast:** source row 4 initially gives probabilities [.9263597131,.0689374879,.0047027734]. Changing indices 30 and 31 from GT to AA gives [.0282645933,.7601864934,.2115488648], so the leading class changes to IE. The worked row 3 instead changes to N under the same local edit. Exact strings and logits are retained in `author-results.json`. Optional aggregate assessment diagnostics are separately labeled post-fit interventions: the default model makes 40 errors, restricting lags makes 177, and disabling gates makes 316, out of 416. These are not retrained alternatives or the answer to the learner’s fresh input.

**Nulls and controls:** unchanged input or exact restoration reproduces original logits within 1e−4. Keeping all 60 lags equals an unrestricted filter on this horizon. An all-N input gives [.0232875645,.0219278373,.9547846317] in the default model; it is not a uniform-probability null. Use it to investigate learned bias under uninformative input. Changing characters after index 30 preserves the first 31 hidden positions up to roughly 3e−6 in the native float32 check; final classification can change because it reads the whole window. Do not turn that hidden-prefix property into a claim of classification invariance.

**Display:** use the labeled DNA editor and aligned original/edited probability bars, highlighting changed positions. Provide a logits table and optional selected-channel filter stems. Show model identity, ablations and “fixed model, no refit” near the result. Follow the result with a focused interpretation and a suggested contrasting experiment, not repeated caution boxes.

**Performance and accessibility:** calculate one current 60-token sequence per run; load additional model weights only when requested. Two direct convolutions of at most 60×60×16 contributions are bounded and require no browser GPU. Do not process the whole native corpus after each edit. A numerical table and keyboard base selectors support narrow screens. Reset restores fresh row 4, default model and unset prediction. Assessment records must not become editable training-selection inputs.

**Phase-two checks:** compare the independent browser implementation with all 460 saved validation logits for each selected fit, including filter generation, normalization, GELU, short-filter orientation, skip and classifier. Check arbitrary sequence edits, all-N input, both supplied edit fixtures, no-op restoration, mode invalidation, error recovery, mobile layout and focus. ## HD — Preserve or approximate the past

**Placement and question:** after the recurrence and finite error bound, on the optional deeper route. Which computations preserve the full filter, and which deliberately alter it or its history?

**Inputs:** fresh signal [2,0,−1,3,1,−.5], residues [.6,.4], poles [.5,−.25], zero initial state. Allow 2–12 inputs in −4…4, one to four residues in −2…2, and poles in −.95….95. The chunk boundary ranges from 1 to L−1; retained filter length ranges from 1 to L. The exact recurrence always uses all chosen modes. The comparison convolution generates its first L coefficients from those same modes. Optional state reset and finite truncation explicitly change the state or filter. A changed chunk boundary carries state by default. Prediction starts unset: same/different versus full convolution, with an optional first changed position.

**Mechanism:** update each mode s_n,t = lambda_n s_n,t−1 + u_t and read y_t = sum_n R_n s_n,t. Generate h_r = sum_n R_n lambda_n^r for r=0…L−1. Carry the last prefix state into the suffix. Truncation sets coefficients at and beyond the retained length to zero. The finite error bound is max|u| times the sum of absolute coefficient errors. Negative poles and residues are legal; use absolute values correctly in the bound. States and signal amplitudes are dimensionless.

**Checked contrasts:** fresh full output is [2,.4,−.65,2.9375,1.503125,.19296875], with state [−.5,−.875] after the first three inputs. Resetting there produces suffix [3,1.6,.225], unlike carrying the state. The separate worked signal [1,−2,.5,3,−1,2] with only two retained lags has observed maximum error .499609375, below its finite bound .903515625. Offer that as a comparison, not a pre-solved fresh default. Modal/direct error is within 1e−12; the measured worked error is 4.44e−16.

**Nulls:** zero input and zero initial state give zero in all forms. Keeping all L coefficients gives no truncation error on this horizon. Carrying state at any chunk boundary gives the same output. All-zero residues also produce zero. A reset at a zero state can match the correct output, and omitted terms can cancel at a particular position. Feedback must calculate the actual case rather than asserting that resetting or truncating always changes every result.

**Display:** show state-register lanes, input strip, exact and truncated coefficient stems, output comparison, and measured error versus the bound. The selected-time card gives previous state, current input, updated state and read. Stepping is optional; it does not replace meaningful user-defined inputs. Narrow screens stack the lanes and selected-time card. The complete trajectory has a text table. A static Hankel-spectrum branch can use the retained exact two-mode example with its finite-horizon qualification.

**Phase-two checks:** independently verify recurrence, direct convolution and carried chunks with negative poles and nulls. Check resets, alternative boundaries, truncation bounds, no state leakage between experiments, prediction storage, keyboard interaction and narrow-screen layout. This lab does not require a trained-filter distillation campaign: it teaches exact modes and explicit finite approximation.

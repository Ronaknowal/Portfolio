## Teaching problem and coverage contract

The learner should be able to compute and implement a masked attention head, assemble independent heads with correct shapes, explain where gradients flow, distinguish attention weights from causal explanations, and inspect a real small attention classifier without confusing its output with a language model or a full Transformer. Start with a receiver choosing messages from donors. The hand arithmetic, value-space geometry, legal-edge graph, shape lanes and actual recorded trajectories need different representations.

Conserve the original useful depth: Q/K/V roles and geometry; self/cross distinction; row-softmax and value aggregation; multi-head projections/output map/parameter counts; scaling derivation; stable softmax and gradients; masking and shifted targets; a complete scratch implementation reconciled with a public API; actual learning and diagnostics; entropy limits; compute/activation/cache costs; appropriate production APIs; failure investigation and independent practice.

Repair the original copy experiment: its code scores all 16 shifted targets for eight independent random source tokens and claims a loss near .0017. Seven of those targets are unpredictable over 31 symbols; the expected irreducible contribution to the all-position loss is `(7/16) log(31)`, about 1.502. A copy-only loss could approach zero, but that is a different denominator. The old manually typed heatmap also disagrees with the stated source/copy lengths. Replace the unsupported numerical learning claims and invented heatmap with retained native results on real trajectories, while keeping a compact, exact target-shift/loss-denominator diagnostic.

Correct the remaining consequential claims at their teaching homes: independently projected Q/K/V are not identical; raw dot product is not cosine similarity; averaging is convex only before output projection/dropout/residual; scaling assumes a stated random initialization model and is not a universal guarantee; causal entropy has a row-specific legal-key bound; entropy does not identify head roles; numerical agreement is not machine epsilon; finite sentinels/all-masked softmax need careful semantics; SDPA and MHA boolean masks have opposite meanings; SDPA dropout must be disabled explicitly in evaluation; a one-query cached decode is not the upper-left rectangular causal triangle. Count multiply-accumulate operations separately from two-FLOP arithmetic and include batch/layers/element size in cache formulas. Preserve historical context without unverifiable first-ever, universal throughput, model-default, current-hardware or future-market claims.

Detailed positional families, cache compression, sparse/linear alternatives and kernel engineering have adjacent owners. Include enough local mechanism and cost distinctions to understand the boundaries. Do not silently make the foundational lesson a survey of every recent architecture or repeat the later derivations.

## Fixed real-data protocol, declared before fitting

Use the UCI Libras Movement source file and original `.names`, inspected in full. It records 360 two-dimensional hand trajectories, each with 45 time-normalized sampled points, for 15 movement classes. The source describes four performers and two sessions but does not provide performer/session identifiers in the supplied rows. This is a row-level diagnostic, not a new-performer or new-session assessment and not a sign-language translator. Class names are taken from the original metadata; point times are ordinal sampled positions, not exact timestamps or physical distances.

Exact-feature inspection found 330 unique trajectories, with 30 duplicate rows. Verify identical labels within each repeated group, keep the first source occurrence, retain all original data and group IDs in provenance/results. Within each class, shuffle unique source row IDs using NumPy generator seed 73; take the first two thirds for training, leave four for testing, and use the intervening rows for validation. This yields 220/50/60 trajectories. The final test has four unique trajectories per class. Never split points from the same trajectory across sets. Without performer/session IDs, exact deduplication cannot establish independent physical recordings.

Compare four deliberately modest models: a pointwise tanh stem plus mean pooling; the same stem with one attention head and a residual addition; the same with two heads; and an order-sensitive linear classifier on the flattened 90 coordinates. Attention width is 24. Bias-free Q/K/V/output maps give one- and two-head models equal parameter counts. Mean pooling is a smaller learned baseline; the ordered linear model is a different inductive bias, not a matched-capacity ablation. Coordinates use `2*x - 1`; this is a fixed conversion, not fitted preprocessing. There are no position encodings, feed-forward Transformer sublayers, dropout or augmentations.

Run seeds 101, 102, 103 for each model; full-batch Adam, learning rate .01, no weight decay, 200 epochs. Select each fit's checkpoint by highest validation macro F1, breaking ties by lower validation cross entropy and exact ties by earlier epoch. Evaluate every declared model/seed on the test once after its checkpoint selection; report all outcomes, not only the winner. Seed 101/two heads is predeclared for the visual, independently of its accuracy. Its trajectory is the first test-row ID from class 4 in split order. The figure must use actual retained weights and probabilities, never hand-drawn semantic alignments. The test has been inspected for this lesson; future learner changes use development data, with a fresh appropriate evaluation required for a new performance claim.

Native checks: reverse all point positions (pooled output must be unchanged apart from roundoff), add five `.75,.75` padding points with correct key and pooling masks (unchanged), omit those masks (contrast), and change the selected trace's 23rd x coordinate to `1-x` (contrast). Edits are hypothetical inputs, not relabeled real recordings. A coordinate edit may keep the top class while changing its probability; feedback must explain the actual measured difference. Do not claim that reversing a recording establishes the true class of the reversed physical movement.

No browser training. Phase two can recompute the small frozen model on an edited 45-point trajectory; retain a readable original control and initially unanswered prediction. Full reruns are an optional native program with small offline inputs.

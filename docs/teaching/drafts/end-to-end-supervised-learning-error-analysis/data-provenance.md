# Wine input provenance

- Data: **Wine**, UCI Machine Learning Repository, DOI [10.24432/C5PC7J](https://doi.org/10.24432/C5PC7J), credited to Stefan Aeberhard and M. Forina (repository citation 1992; repository donation recorded in 1991).
- Question and population: chemical measurements of wines from three cultivars grown in one Italian region. This is cultivar recognition, not taste/quality scoring or clinical data. All 178 specimens and 13 measurement columns are retained.
- License: [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/). Attribute the dataset and identify the extraction changes when redistributing. UCI's Wine content and license were inspected on 12 September 2026; the direct `/dataset/109/wine` fetch failed in the research tool, while the repository's numeric-ID route `/dataset/109/isolet` returned the Wine page, DOI, dimensions and license. Use the DOI as the learner-facing canonical link, not that misleading alternate suffix.
- Offline source: scikit-learn **1.9.1** `load_wine()` bundled data, documented by [the API](https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_wine.html). No UCI zip was downloaded successfully during this turn; do not claim a byte comparison to its original archive.
- Changes: export numeric measurements with `%.8g`; retain source row order; add `specimen_id=1..178`; use scikit-learn's feature names; store its zero-based class labels as `cultivar=0,1,2`, corresponding to UCI labels1,2,3. No missing values introduced, no filtering, imputation or scaling written into the CSV. IDs and target are never model features.
- File: [wine.csv](wine.csv), 12,100 bytes. SHA-256 `34ced17cfa0a96bf5ae5c25565da075c612145b20368fc2455e5e8f966e818be`.
- Measurement units: preserve source numeric scales and chemical feature names. The inspected UCI table does not specify a unit for each field; figures must not invent one. The lesson avoids treating a raw color-intensity threshold as a biological boundary.
- Split: first stratified holdout of36 with random_state21; then stratified validation36 from the remaining142 with random_state22; train106. Full one-based IDs are in [calculated-inputs.json](calculated-inputs.json). Actual temporal/group metadata is absent, so the manuscript states the scope of the retrospective sample comparison.
- Models, fitted training state protocol and results: [author-calculations.py](author-calculations.py), NumPy2.3.5/scikit-learn1.9.1/Python3.12.14, CPU. All candidates train only on106. The selected already-fitted model is evaluated on36test rows without refit. `validationRows` contains only36development specimens per candidate; test is excluded from the interactive diagnostic.

The optional acceptance queue is a separate constructed ten-case fixture in the JSON. Its correctness labels and scores are invented to expose coverage/cost arithmetic and are labeled as such; they are not measurements of this Wine classifier. The Wilson interval is a calculated binomial illustration with explicit sampling limitations, not an empirical confidence interval certified for this stratified design.

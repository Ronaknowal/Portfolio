Removed/corrected false claims: subnetworks are uniformly sampled only for equal keep/drop probability; preserved means do not imply exact nonlinear model averaging or unchanged expected loss. Dropout does not guarantee each unit works alone or robust distribution shift. Parameter count and indefinitely widening gap are not definitions of overfitting. All-modern-library/default architecture absolutes, ViT parameter misstatement, tiny universal accuracy/runtime deltas and “large data cannot overfit” omitted. Original stochastic depth used survival-scaled evaluation; source conflated layer count with block count and schedule indexing. Per-row masking is a stochastic-depth variant, not a guarantee of clean BatchNorm statistics. LN/GN lack running-statistic mismatch but are not invariant to masks. tau inverse is variance, not precision. MC spread is not automatically calibrated; fixed dropout does not learn per-weight rates or double parameters. Conformal/ensemble methods have their own assumptions, so no automatic replacement safety claim. Attention weights after inverted dropout need not sum1. An all-zero sampled contribution is not permanent pruning or automatic saved computation.

# Feature selection: visual and investigation contracts

This is a content-first specification. No component, browser integration or phase-two verification is claimed. Pair each representation with its named manuscript explanation; do not collect all visuals in a final gallery. Exact author evidence is in `calculated-inputs.json`, produced by `author-calculations.py`. The published implementation should import only compact required fixtures and this topic's components, not the author program or entire JSON by default.

## Shared learning and interaction behavior

Every investigation begins with an unanswered, input-bound prediction. Show editable entities and the question first, let the learner record a choice or their own prediction, and reveal the computed outcome on **Apply**. Applying without a prediction may still inspect the mechanism, but must not silently record a correct answer. Changing inputs, model, metric, reference population or grouping clears the comparison/assessment and marks the result stale until applied again. Preserve the draft prediction for editing if useful; never evaluate it against old inputs. Reset restores the named fixture, clears prediction and returns to an unrevealed state. Hints and worked explanations start closed and do not select the learner's answer.

Use proper number inputs with visible labels and finite-value validation; no coercion of blank text to zero. Retain meaningful domain values, including negative linear measurements and zero counts. Invalid edits show the local reason and preserve the last committed case separately, without showing stale output as current. Controls work by keyboard; focus and state changes are announced. Color accompanies labels, row IDs, edge styles or signed numbers. Offer the complete value table/text trace alongside each drawing. No motion is necessary to understand a result; honor reduced motion and provide step buttons for optional transitions. On narrow screens stack stages vertically, retain source/donor identities, and allow bounded table scrolling rather than shrinking text. All predictions and solutions have a readable text equivalent.

Five investigations answer different questions. Count evidence is not a model-performance chart; a complete finite-world search is not cross-validation; a fixed-model perturbation is not refitting; coalition allocation is not a causal intervention; raw-input inference in the observed tree is not training. Keep these distinctions visible in the labels, not in repeated warning boxes.

## I1 — Count tiles and uncertainty reduction (§2)

Render a two-by-two contingency table as editable integer counts with target columns Y=0/1 and input rows X=0/1. Default `[[3,1],[1,3]]`. Include row/column sums and a unit-square probability mosaic whose cell area equals count/total; use an adjacent conditional bar for each nonempty row. Below the conditional bars show entropy before observing X, weighted entropy after observing X and their difference, in **bits**. A zero-count row contributes zero rather than requiring a conditional distribution. The initial question is “Will knowing X remove all, some, or none of the target uncertainty?” Optional numeric prediction is a separate unanswered input.

Compute only on Apply from the four entered counts. Use p>0 terms only in logarithms, base 2, and validate nonnegative integers with positive total. Scale counts safely without factorials; cap each at a documented UI bound such as 10,000 to keep tile rendering independent of sample size. Do not draw one DOM node per observation: a cell is one rectangle. The complete table is always available to a screen reader.

Checked default: H(Y)=1, H(Y|X)=0.8112781244591328, I=0.18872187554086717. Each row has an imperfect preference, so the two conditional bars have identical entropy despite opposite dominant labels. Contrast `[[4,0],[0,4]]`: information 1 bit and zero conditional uncertainty. Null for association `[[2,2],[2,2]]`: information 0. Multiplying all four original counts by any common positive integer leaves the empirical probability/information values unchanged; the sample size label changes, and the explanation states that population-estimation evidence is a different question. A zero target column has H(Y)=0 and I=0, not an error or division by zero. Practice fixture `[[2,0],[0,6]]` gives H(Y)=I=0.8112781244591328 and H(Y|X)=0.

Feedback refers to the actual entered rows and conditional proportions; no canned “high MI” threshold. Add a folded calculation trace showing count→joint probability→marginals→four nonzero log contributions. The entropy difference and direct MI sum must agree within 1e-12 for the fixtures.

## I3 — Donor rows reveal what permutation changes (§4)

Display four editable rows with two input columns and a target, plus editable linear coefficients w1,w2 for fixed prediction `w1*x1+w2*x2`. Default both columns and y are `[-1,-1,1,1]`. Coefficients default `[1,0]`. Display a donor-row permutation as four selectors with source row IDs; validate that each of 0,1,2,3 occurs exactly once. Default `[2,3,0,1]`. Selection modes are first column, second column, or both as a group; for the group use the same donor map for both columns. The model is explicitly fixed throughout; there is no automatic fitting or fallback to another input.

The learner predicts whether loss increases, stays equal or decreases; optional magnitude is MSE increase, with squared target units. On Apply draw donor arrows from source cells to altered rows, preserve untouched cells, then show baseline/altered predictions, each squared residual and averaged loss. A valid shuffle can retain fixed points. The output formula is altered MSE minus original MSE, so negative results remain valid and visible. Default first-only model yields increases `[4,0,4]` for first/second/group. Second-only `[0,1]` yields `[0,4,4]`. Average model `[0.5,0.5]` yields `[1,1,4]`. This three-model contrast is central: it directly refutes a claim that a fitted model automatically substitutes a duplicate measurement after shuffling.

Identity donor map `[0,1,2,3]` is an exact null for every model/input. A column with coefficient zero is another exact null when permuted alone. For average-model practice donor `[0,2,1,3]`, single-column altered prediction is `[-1,0,0,1]`, MSE increase 0.5; group prediction `[-1,1,-1,1]`, increase 2. Use input edits to change associations and targets; compute every result from current values. Grouped shuffling preserves within-group records, not their relation to other inputs/target. No automatic conclusion about “importance in the world.” A folded text trace lists row i, donor row, changed cells, prediction and residual so arrows are optional.

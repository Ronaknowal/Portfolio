# Author calculation protocol

Fixed before first training execution, 13 September 2026. These are bounded teaching experiments, not a model-selection campaign.

Use the UCI Wine observations bundled with scikit-learn 1.9.1, exporting all 178 rows and 13 features with original row IDs and labels mapped from UCI 1–3 to 0–2. Establish one split using NumPy `default_rng(2026)`: within each class, permute row IDs; take 24 training, next 12 validation and remaining test rows. Retain the exact split. Fit feature means and population standard deviations on the 72 training rows. The 70 test rows remain untouched by fitting, tuning and reported metrics.

For the small-data check use the first four retained training IDs of each class, 12 examples total. For all Wine fits use float64 CPU, one Torch thread, deterministic algorithms, a 13→32 tanh→3 network, full-batch mean cross-entropy, SGD learning rate 0.05, momentum 0.9, no regularization, no augmentation and no schedule. Tiny clean and deliberately omitted-update runs use seed 7, 120 updates. Full clean and label-shuffled fits use seeds 3, 7 and 19, 400 updates each. Shuffle the 72 training targets once using NumPy `default_rng(991)`, identically for all initialization seeds; preserve validation labels and all features. Measure loss/accuracy at the fixed initial state and after every update using evaluation mode and no-grad; retain both supplied-target and original-target training scores for the corrupt-label treatment. Report all planned outcomes including weak or null contrasts; do not increase training time or select a better seed after seeing results.

For activation scale diagnostics inspect the seed-7 initial first layer on the same 72 standardized inputs and those inputs multiplied by 100; compare tanh absolute-output quantiles and mean derivative `1-tanh(z)^2`. This is a scale intervention, not a universal saturation alarm threshold.

For restart teach an exact constructed scalar momentum recurrence first. A separate actual Wine checkpoint probe uses float64 CPU, a 13→8 tanh→dropout(0.25)→3 model, seed 23, data-order generator seed 88, SGD lr 0.03/momentum 0.9, batch size 12 and StepLR(step_size=3,gamma=0.5) after each update. Save after five completed updates, with cleared gradients and cursor 60 in a 72-row permutation. Compare uninterrupted training to full restore through update 12, and to omission of one category at a time: optimizer, global Torch RNG, active order/cursor, or scheduler state. Restore RNG only after constructors. Record next batch IDs, losses, learning rates, final maximum parameter difference and exact equality; no test metrics.

Verify the elementary finite-difference and scalar restart examples independently of the neural fit, and exercise the exact closed practice values and specified lab null cases. All numerical outputs must come from executed programs or explicitly labeled exact arithmetic. Browser models, figures and controls remain specifications only.

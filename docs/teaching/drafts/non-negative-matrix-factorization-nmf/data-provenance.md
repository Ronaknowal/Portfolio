# Offline NMF digit data

E. Alpaydin and C. Kaynak (1998), *Optical Recognition of Handwritten Digits*, UCI Machine Learning Repository, DOI [10.24432/C50P49](https://doi.org/10.24432/C50P49), [source page](https://archive.ics.uci.edu/dataset/80/optical+recognition+of+handwritten+digits), inspected 12 September 2026. UCI specifies [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Retain this attribution and the subset description with the CSV and derived factor data; original collectors do not endorse this lesson.

The source question is handwritten digit recognition. The collection reduced normalized 32×32 handwritten bitmaps into nonoverlapping 4×4 blocks, counting foreground pixels in each. Thus the 64 features form 8×8 block-count images with values 0…16. This is not MNIST, a clinical dataset or an unprocessed camera image.

The supplied `digits-300.csv` is the byte-identical established teaching subset from the preceding manifold lesson: from scikit-learn 1.9.1 `load_digits()` (1,797 rows, original UCI test-set portion), take the first 30 rows of each digit label 0…9 and sort their loader indices. Labels therefore affect subset selection; the early-row subset is not population-representative. Data was copied read-only into this topic so the pending packet is self-contained. No measurements were changed and no new network download was required. SHA-256: `d93f963c4b2610eb07122a312eec3ddceac18a031477370d71e33835eced728e`.

CSV columns: `source_row` original zero-based loader index, `digit` diagnostic target, then `pixel_0`…`pixel_63` row-major block counts. Only these 64 counts enter NMF, divided by 16; no centering, learned per-feature scale or imputation. Split by `train_test_split` with seed 19 and stratification: first 60/40%, then the latter half/half, giving 180 training, 60 validation and 60 test rows. Exact indices and native outputs are in `calculated-inputs.json`. Writer IDs are unavailable here; do not claim a new-writer evaluation.

The author execution used Python 3.12.14, NumPy 2.3.5, scikit-learn 1.9.1 and `author-calculations.py`. Candidate NMF fits use k = 1, 4, 8, 16; seeds 7 and 19; random initialization; CD; Frobenius loss; no penalty; max_iter = 2000; tol = 1e−5. The inspection case k = 8, seed = 19 was declared for readable images, not selected by validation. Test inputs and dictionary/activations/reconstruction are actual outputs. PCA with eight components and full SVD, plus the training-mean image, are also measured. No elapsed-time, classification accuracy, biological identity or optimal component count claim is supplied. Random-seed repeatability is tied to this software version and settings.

Hand matrices, exact loss comparisons, zero-lock case, nonnegative-rank matrix and three-band spectrum are original constructed teaching fixtures, distinguished from this real dataset. Their units and simplifications appear in the manuscript/specifications. Runtime export, displayed-program campaign, actual browser figures and independent implementation review remain deferred.

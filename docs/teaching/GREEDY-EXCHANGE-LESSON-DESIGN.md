## Implemented visual contracts

- `IntervalSelectionLab`: at most six intervals, bounded integer endpoints and positive durations; identity remains input position. Optional value field permits an explicit weighted counterexample, not an optimality claim for a heuristic. A general compatibility scan compares earliest-finish/start/duration candidates fairly; only the optimized native earliest-finish function uses its single latest-finish invariant. Exact exhaustive oracle is restricted to these tiny inputs and labeled extra diagnostic work.
- `DeadlineExchangeLab`: bounded positive processing times and integer deadlines, all available at time zero, no idle time. Swap adjacent pairs and show signed lateness versus nonnegative tardiness. A swap of an inverted deadline pair cannot increase the maximum, although individual jobs can become later and ties need not yield a unique order. Typed changes apply explicitly; reset restores the fixture.
- `FractionalCapacityLab`: three fixed weight/value records with editable capacity and whole/fractional policy, keeping the same counterexample while the actual legality of fractions changes. Density order determined by cross-products; exact numerator/denominator records avoid presenting rounded display values as the model. Whole-item density is labeled a candidate rule; a finite subset oracle shows its failure. Fractions are meaningful only under linear divisible benefit and no setup/dependency costs. Thin segments retain proportional width and exact table values; labels that would clip are omitted from the strip, and unused capacity has a separate readable amount.

## Algorithm and accuracy contracts being established

- MH acceptance uses the complete ratio and a current state with positive finite target density. Symmetric proposal is a stated specialization. A larger target alone need not be accepted under asymmetric q. Every iteration contributes its resulting state, including repeats. Proposal support/current-state validation and log-space zero handling are explicit.
- HMC: unit mass in the primary native/visual example, U=-log target, K=r²/2, fresh normal momentum, leapfrog half-kick/drift/half-kick, reversible volume-preserving proposal with momentum flip and Metropolis energy correction. Compare exact Gaussian dynamics and independently check reversibility/Jacobian, not just sampled means. Avoid claiming a gradient step is posterior sampling.
- NUTS: choose the original simplified slice-based Algorithm2 for a fully inspectable implementation, with finite depth cap and explicit high-energy guard. Read the original derivation and pseudocode carefully: a subtree that internally turns must be excluded, while a newly completed whole-tree turn has a different candidate-set consequence. Candidate selection/state identity must match this exact algorithm. Memory cost of stored candidates is acknowledged; this is not a clone of current Stan's multinomial implementation. Adaptation is explained separately from per-iteration dynamic trajectory length.
- Diagnostics: distinguish invariance, convergence from an initial state, Monte Carlo CLT assumptions, function-specific ESS/MCSE and full posterior uncertainty. ESS can exceed number of draws for useful anticorrelation. R-hat near1 cannot detect every unvisited mode or prove convergence. Rank-normalized/folded modern diagnostics need a verified definition. The inspected Stan2.39 analysis page displays `(rank−3/8)/(S−1/4)`, whereas the [original paper's corrected v5 equation14](https://arxiv.org/html/1903.08008v5) gives `(rank−3/8)/(S+1/4)`, the symmetric Blom plotting-position convention. Use the latter and check against independent rank/normal-quantile implementations; preserve this evidence rather than reproducing the documentation discrepancy. Also do not plug rank bulk-ESS into raw posterior-mean MCSE as if the transformed and original functions were identical. Do not call a simple lag-one estimate a production ESS.
- Discrete parameters need an appropriate sampler or marginalization; smooth HMC cannot blindly differentiate discrete jumps. Constrained continuous parameters need change-of-variable Jacobians for transformed target densities. A Beta/log-odds example can connect directly to MLE's coordinate discussion without repeating MAP.

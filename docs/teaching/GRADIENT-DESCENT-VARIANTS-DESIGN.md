## Coverage and title decision

Retain the existing title and stable route. The parenthetical names identify the principal families without claiming that no other variant belongs here. Momentum, Nesterov and AdamW are necessary parts of this lesson; adding every name would make an already long title less useful. Preserve the original scalar momentum example (`theta=5`, gradient `2*theta`, learning rate .1, momentum .9, three iterates 4, 2.3, .31), mini-batch motivation, coordinate adaptivity, large-batch layer scaling and controlled comparison/diagnosis. Replace the original unexecutable NumPy trust-ratio fragment with a complete, explicitly defined implementation. No useful original concept is removed.

Repair the original implication that every first-order update moves opposite the current gradient: momentum can keep moving after the current gradient reverses. Full-batch gradients are a valid baseline and may be appropriate for small deterministic problems; do not call them universally impractical. SGD can mean one random observation or, commonly, a mini-batch method. Unbiasedness requires a specified sampling contract. “AdamW is a strong default” becomes a reasoned comparison under a stated workload rather than a universal recommendation or generalization guarantee.

Convex Optimization owns convexity, certificates, deterministic smooth steps and proximal reasoning. Here the learner should be able to compute and explain **sampling, memory, coordinate scaling, decay, layer scaling and persistent optimizer state** as distinct decisions. ## Depth and technical contracts

- Define `theta`, per-example loss, empirical mean, gradient vector, update count and sample/batch size before their equations. If probability notation is used, first interpret expectation as the exact average over a finite set of possible batches. Fresh uniform sampling conditional on current parameters differs from shuffled without-replacement epochs.
- Derive EMA history, unnormalized momentum scaling, Nesterov lookahead, accumulated versus forgotten squared gradients and Adam's two bias corrections. Second raw moment is not centered variance. A rare-coordinate example gives AdaGrad a concrete application without claiming every sparse optimizer touches only nonzero entries; dense moments can move a coordinate after a zero current gradient.
- Keep epsilon outside the square root for the stated NumPy rules and current PyTorch-compatible basic formulas; framework variants may differ. Zero denominators and zero histories have explicit behavior. Show sensitivity to epsilon/gradient scaling rather than claiming exact invariance with nonzero epsilon.
- Derive AdamW `theta_new=(1-eta*lambda)*theta-eta*adaptive_direction` with moments built from data gradients only. The decay amount depends on the learning-rate schedule and which parameters receive decay. Plain SGD's coupled-L2 equivalence does not automatically survive momentum/adaptive history. State parameter-group policies as chosen modeling conventions.
- LARS variants disagree about placement of learning rate, momentum, decay and trust coefficient; provide the exact chosen convention, not a falsely universal equation. LAMB uses separate raw and corrected moments; corrected values must not overwrite the raw recurrence. Its layer ratio is applied to the combined adaptive direction/decay in the chosen contract, so it is not simply AdamW plus an unrelated rescale.
- A small synthetic quadratic cannot establish neural-network generalization or distributed throughput. Noise can increase a particular step's loss; a constant-rate stochastic iteration can retain variance. Adaptive methods still require assumptions, tuning and stopping criteria; the original Adam convergence claim is not repeated without the later correction/counterexample context.
- Practical native programs use NumPy only, already installed at 2.3.5 with Python 3.12.14. PyTorch is **not installed**; do not claim its optimizers were executed. Annotated current API references explain production conventions, while complete educational NumPy code exposes mechanisms and is actually executed. No package installation is presently needed.

## Scope and completed teaching

The [individual design](GREEDY-EXCHANGE-LESSON-DESIGN.md), [lesson](../../src/learn/data/topics/greedy-algorithms-exchange-arguments.jsx) and [blueprint](../../src/learn/data/curriculum/blueprints/greedy-algorithms-exchange-arguments.js) teach how to propose a local rule, find its failures and establish its guarantee. Existing order remains Backtracking → Greedy → Dynamic Programming. The individual prerequisites now name the actual preceding Complexity, Binary Search/Sorting, Backtracking and Heaps foundations, replacing a generic dependence on the later Algorithm Correctness topic. Necessary proof steps are supplied locally; later proof theory remains a deepening link.

- Feasibility versus the objective, a candidate rule versus a theorem, maximal versus maximum, and the quantifier that some optimum can contain the chosen action. Coin examples show both a suboptimal feasible result and getting stuck despite an existing solution.
- Half-open positive-duration interval selection: three candidate rules, explicit counterexamples, a first-choice exchange, residual optimality/induction and a complete aligned stays-ahead proof. Duplicate occurrences, ties, negative native times and empty input have explicit contracts. Weighted values expose the failed count-preserving exchange.
- Assigning every interval to minimum resources: start order, a heap of last finishes and an overlapping-request lower-bound witness. The objective is distinguished from selection and interval union.
- Offline nonpreemptive deadline scheduling: all jobs available at zero, signed lateness versus clipped tardiness, removing idle time, a pairwise inequality, unchanged tail and finite inversion elimination. Shortest processing time for total completion, tardy-job counts and release-time assumptions are distinguished.
- Fractional capacity allocation: density, equal-weight exchange, exact rational arithmetic, linear/divisible assumptions and the failed whole-item rule. The exact 240/160/220 comparison motivates the next DP topic without claiming to solve it here.
- Huffman prefix trees: leaf/code interpretation, frequency-depth objective, deepest-sibling label exchange, contraction, serial heap ties, actual encoding/decoding and the merge-cost identity. Framing, one-symbol empty codes, Python code points, code-output storage and recursion depth are qualified. Optimal repeated file merging is a separate application of the same modeled objective, not an empirical benchmark.
- Forward-jump reachability: at-most jump semantics, a certified continuous prefix, the unreachable-gap argument and the distinction from choosing the longest physical jump. Exact jumps, path output and minimum jump count change the state/output contract.
- Proof forms, changed assumptions, optional matroid augmentation and an interval counterexample, exact versus approximate guarantees, and future graph proof boundaries.
- Independent covering-point, threshold-matching, released-job and Huffman exercises with hints and explained solutions, followed by curated external practice.

## Coverage limits

This pass tests rendered control names, layout boundaries and actual range interactions in the reached states. It does not prove every possible input combination, hidden branch, paragraph or older unreviewed lesson is perfect. Static scientific figures can remain static when their presentation is honest; a genuine null result can remain unchanged. No learner-prediction feature, optional guess or reveal gate was added.

For future controls, the model's accepted domain must match every value the UI can emit, including intermediate slider values. A slider and a typed editor for one quantity need individual accessible names and must agree on the exact current value. Check caught console/rendering errors as well as uncaught page errors: this K-Means failure was caught correctly by the reader's recovery boundary, so an uncaught-error-only check would have missed it.

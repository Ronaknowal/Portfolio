- Nine sequences across RNN/LSTM/GRU start with nonzero hidden state and, for LSTM, nonzero cell state. Downloaded NumPy calculations match native hidden outputs and class probabilities; final LSTM cells also match. Maximum scratch/native difference is `1.6653345369377348e-16`.

- Unsorted lengths `[7,2,5]` with nonzero initial hidden/cell states are packed through a bidirectional LSTM. Both returned directions and both state tensors match separate unpadded sequences despite deliberately large padding values.

## Findings and resolved changes

1. Continuous number controls originally allowed off-step values while their range inputs could round the displayed position. The author changed continuous controls to `step="any"`; integer structural controls retain integer steps. Values are shared directly with the calculations.
2. Dragging a point originally attached its center directly to the pointer. The author now stores the inverse-SVG grab offset and subtracts it during movement, with continuous bounded coordinates and numeric alternatives.
3. LSTM accounting was initially numerical lanes alone. The added signed bars share a common zero and fixed `[-3,3]` scale, matching the allowed cell/write range and exposing cancellation.
4. GRU reset placement initially relied on tables. Added source/destination gate drawings show all four actual mixing edges, their signs/weights and the distinction between source scaling and destination scaling; exact bias/contribution values remain alongside them.
5. Downloadable provenance retained an unqualified content-first status. Its current delivery prepend now distinguishes preparation history from implemented behavior and preserves the original data/method limits.
6. Shared SVG text/axes inherited green tints. Scoped recurrent overrides make labels and both ordinary/zero axes neutral without changing other lessons.
7. During the author's perceptual pass, point labels moved inside opaque numbered circles so lines do not run through labels. Text passes pointer events to the circle; grab-offset behavior is unchanged. Initial pen coordinates are serialized as their exact decimal grid values, removing binary-display noise such as `0.6200000000000001`; the maximum numerical change is floating-point roundoff, and the author reran affected native parity checks. The final source changes were independently inspected before binding.
8. The final `maxDifference` helper flattens each operand once and reduces the maximum in linear time, instead of repeatedly flattening the right operand per element. Unequal lengths now fail explicitly. Independent inspection reconstructed the exact previous source to confirm the change's scope, then checked empty/nested inputs, both unequal-length directions and a 200,000-element comparison. The parent reran the eight author and six complementary model groups with unchanged results; native calculations were reused. The final source binding includes this optimization.

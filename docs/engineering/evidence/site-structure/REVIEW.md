  warning remains; it is not imported on Home or Articles.
- `verify-articles.mjs` passed schema/date/ordering, draft exclusion, explicit lazy
  imports, safe Markdown/GFM, no-overwrite draft creation, escaped HTML metadata
  and Pages entry/fallback checks. Temporary fixture roots clean up in `finally`.

The full existing browser automation script was updated for relocated sources but

## Ignore changes and preservation

Root scratch/build rules are now anchored. This reveals previously hidden,
untracked archived teaching evidence and an existing teaching log; those files
were preserved, not created by this task or deleted as cleanup. Machine-global
Git excludes are outside the deterministic repository check. Five public Python
`__pycache__` directories containing generated bytecode were removed because Vite
would otherwise copy them into deployments. Source Python assets remain intact.

No articles were authored for the owner, no independent app was invented, and no
commit, push, domain change or remote deployment was performed. GitHub Pages
fallback-only nested learning links still have its HTTP-404 limitation; published
section/article routes receive real entry files. Article rendering remains client
side, with no claim of full SSR. Network-failure injection for reader retry was
not part of the browser check.

## Visuals and practice artifacts

- Seven SVG figures are rendered from the exact displayed Python, under `public/learn-assets/programming-three`. Charts fit the reader initially, can be enlarged for scrolling, and have full-size links, descriptive alternative text and numerical captions.
- The notebook explorer lets a reader create stale state, encounter an undefined variable, recompute a result and restart. It is explicitly a bounded simulation, not an arbitrary Python interpreter.
- Source and executed `.ipynb` downloads are generated by the notebook example. Each has three executable code cells and a short narrative. The generator refuses to overwrite existing notebooks.
- New shared components are opt-in: `PlotOutput`, `NotebookStateLab`, and scoped plotting CSS. No existing reader behaviour was redesigned.

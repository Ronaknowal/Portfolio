# Articles source

Create a draft with `npm run article:new -- --slug my-article --title "My article"`.
Each stable-slug folder contains `metadata.json` and `body.md`. Only entries explicitly
marked `published` enter the website build. No articles have been authored on the owner's behalf.

Read [the authoring guide](../../docs/writing/ARTICLE-AUTHORING.md) for the schema,
images, references, preview, publication and verification. Keep this source in Git.

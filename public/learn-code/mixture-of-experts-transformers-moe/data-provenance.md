# Optical digit routing: data and calculation provenance

Research/write phase, 13 September 2026.

## Source, rights and transformations

Optical Recognition of Handwritten Digits was contributed by E. Alpaydin and C. Kaynak, Bogazici University, July 1998. The [UCI dataset page](https://archive.ics.uci.edu/dataset/80/optical%2Brecognition%2Bof%2Bhandwritten%2Bdigits) and its [CC BY 4.0 license](https://creativecommons.org/licenses/by/4.0/) were checked for this packet. The complete original optdigits.names was reread. It describes 32×32 normalized bitmaps partitioned into 4×4 blocks; each output count is 0–16, giving 64 features arranged as an 8×8 grid. This is not a timestamped pen trajectory.

This packet reuses verified byte-original files from the earlier xLSTM packet rather than downloading duplicate archives. ## Declared and executed model comparison

The protocol was recorded in design.md before fitting. The complete moe_study.py contains data loading, patch projection, positional vectors, two-head attention, normalization, residuals, dense/SwiGLU expert FFNs, gather/scatter dispatch, training, checkpoint selection and scoring. The comparator is width-32 dense FFN; sparse models have four width-16 experts, k=2 selected-logit softmax, no capacity drops. Whole models have 3,162 and 4,762 parameters. Expert matrix MACs per token match, but routing overhead, stored parameters and initial classifier draws differ. Do not call these equal whole-model capacity or measured-time comparisons.

Conditions are dense and MoE balance coefficients 0/.01/.1. Seeds 17/41/73 give twelve planned fits. Within each seed the three MoE settings begin from identical model parameters and use identical sampled row sequences. Each run uses 240 AdamW updates, lr .003, weight decay .001, default betas .9/.999, batch64 sampled with replacement using a dedicated generator seeded 10000+seed, gradient norm clipping1. Float32 CPU, one thread, no dropout, augmentation, z-loss or later rescue search. Evaluate validation task CE at step1 and every20; keep its strict minimum, selecting the earliest equal value. All twelve runs completed once. All selected checkpoints, curves, original-role confusion matrices and route counts are saved.

The declared stress zeros the lower four image rows for every assessment input and preserves original labels as stress-scoring targets. It does not describe naturally observed zeroed images. All clean/stress outcomes remain, including unfavorable sparse results. No assessment result selected new hyperparameters, seeds or update budgets. Uniform prediction CE ln10 is a mathematical reference, not a fitted model. No GPU/latency or large-model scaling experiment ran.

Files: study-results.json holds all measured records; fitted-models.json contains every selected parameter dictionary as plain numeric arrays. The complete program is also embedded in a closed manuscript block. Python3.12.14, NumPy2.3.5 and PyTorch2.14.0+cpu were the actual environment; no shared dependencies were installed.

For all nine selected MoE fits, it compares the sparse gathered path with a separate dense-all-experts reference on four validation images, in float64. This author-check correction required no refit or model change.

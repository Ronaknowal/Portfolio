Whitespace separated, LF line endings, 1,484 rows: a sequence identifier, eight numeric
localization scores (mcg, gvh, alm, mit, erl, pox, vac, nuc) and an original location label.

What this lesson does with it, and does not do to it: the served file is unchanged. The
analysis retains the first occurrence of each of the 22 protein identifiers that appear
twice with byte-identical scores and labels, leaving 1,462 distinct proteins and all 51 ME2
positives. It defines a binary target, original location ME2 against every other location,
and uses six of the eight scores (mcg, gvh, alm, mit, vac, nuc). That is a teaching task
definition, not a clinical or diagnostic claim. Interpolated feature vectors generated by
SMOTE are synthetic numerical training data, never synthesised protein sequences.
This lesson serves its own copy so that no other lesson's asset edit can change it.

Data and programs served by the Calibration & Conformal Prediction lesson
========================================================================

This lesson serves its own copies of everything it runs on, so that no other
lesson's asset edit can change what this page executes or displays. Several
sibling lessons serve a byte-identical banknote extract under their own
directories; this page references only the files in this directory.


1. Banknote Authentication  ·  banknote-subset.csv
-------------------------------------------------
Volker Lohweg (2012). UCI Machine Learning Repository.
https://doi.org/10.24432/C55P57  ·  https://archive.ics.uci.edu/dataset/267/banknote+authentication
Licensed CC BY 4.0: https://creativecommons.org/licenses/by/4.0/

21237 bytes, SHA-256 d28fa993ed459d2f706816395475af08eebd2f394be67f2ad42dd9b511fc6b5a.
These are the unchanged bytes of the subset prepared for this curriculum's content
phase, copied from the frozen content packet rather than regenerated. The original
archive is https://archive.ics.uci.edu/static/public/267/banknote+authentication.zip
(SHA-256 1e2acd9a2085fadf3d8145c12d3d22af853320d52294a6590c2eaf75fdc05227), whose
member data_banknote_authentication.txt has SHA-256
d0539aaed2139ba7a587b3e34fb345ce503ff7d5d33dbf9912d8e195ce425cb9. That archive was
retrieved on 2026-09-12 for an adjacent packet; no fresh download is claimed here.
The SHA-256 above pins exactly what this page serves.

Selection: NumPy default_rng(23).permutation(1372)[:480]. The original file has 1372
rows; 480 are retained, and each row keeps its one-based original row number in the
source_row column. All 480 source_row values are distinct and run from 3 to 1370.

Comma separated, CRLF line endings, a header row and 480 data rows of seven columns:
source_row, split, variance, skewness, curtosis, entropy, class. The spelling
"curtosis" is the source record's own. The four measurements are wavelet-derived
statistics of banknote images; the source record supplies no units for them, and
none are invented here. Their observed ranges in this subset are variance -6.7387 to
6.5633, skewness -13.6779 to 12.7302, curtosis -5.2861 to 17.6052 and entropy
-7.7853 to 2.1353. The class column holds the codes 0 and 1, 275 and 205 rows
respectively. The source record does not state which physical condition each code
names, so this lesson does not infer one: the codes are used as supplied.

The split column carries the LEGACY labels of the packet that first prepared this
extract: 320 "pool", 80 "development", 80 "test", in that order. This lesson
subdivides them differently and by position, which is what uncertainty_experiments.py
does:

    rows   1-240   base fit           (learn the scaler and the classifier)
    rows 241-320   probability calibration   (fit the map from score to probability)
    rows 321-400   conformal calibration     (choose the rank threshold)
    rows 401-480   assessment                (measure; never used to choose anything)

The third role is separate from the second on purpose. Probability calibration is
itself training, so its observations are not scored symmetrically with a fresh
example and cannot serve as an ordinary split-conformal calibration set.


2. Airfoil Self-Noise  ·  airfoil-subset.csv
--------------------------------------------
Thomas Brooks, D. Stuart Pope and Michael Marcolini (1989). UCI Machine Learning
Repository, donated 2014.
https://doi.org/10.24432/C5VW2C  ·  https://archive.ics.uci.edu/dataset/291/airfoil+self+noise
Licensed CC BY 4.0: https://creativecommons.org/licenses/by/4.0/

24603 bytes, SHA-256 5839135483aa9c45bac8416d9bbb0b1966858a21758beb4a8fb9b1fa1dd83bb5.
Unchanged bytes of the content packet's extract. The source archive
https://archive.ics.uci.edu/static/public/291/airfoil+self+noise.zip was downloaded on
2026-09-12 (SHA-256 5c7767ba53ad827d3f48ba1eb9434117f4892df8f10bc4c99e118a9e8a7ae07c),
member airfoil_self_noise.dat SHA-256
74c75fd71783f1e6b71f8a622b993dc592897a97cd689c5090a07147a1b097b3.

Selection: NumPy default_rng(67).permutation(1503)[:480] from the 1503 original rows,
with the one-based original row number kept in source_row. All 480 are distinct and
run from 1 to 1503. Every original numeric string is preserved exactly; the only
additions are the source_row and split columns and descriptive, unit-bearing column
names.

Comma separated, CRLF line endings, a header row and 480 data rows of eight columns:
source_row, split, frequency_hz, attack_angle_deg, chord_length_m,
free_stream_velocity_m_s, displacement_thickness_m, scaled_sound_pressure_db. Units
are the source record's: frequency in hertz, angle of attack in degrees, chord length
in metres, free-stream velocity in metres per second, suction-side displacement
thickness in metres, and the target as scaled sound pressure level in decibels.
Observed ranges here: frequency 200 to 20000 Hz, angle 0 to 22.2 degrees, chord
0.0254 to 0.3048 m, velocity 31.7 to 71.3 m/s, thickness 0.000400682 to 0.0584113 m,
and the target 104.13 to 140.158 dB.

The UCI variable table tags angle of attack as "Binary". Its own prose and the actual
multi-valued measurements describe a continuous angle, so this lesson treats the
observed degree values as a continuous input rather than propagating what appears to
be a metadata error in the source table.

The split column is used directly and is read by name, not by position:
240 "train", 120 "conformal", 120 "test", in that order.

An interval width in dB is a width on the supplied decibel scale. It is not a linear
acoustic-pressure difference, and the two are not interchangeable.

Interpretation limit: these are wind-tunnel measurements, and a frequency sweep shares
its experimental settings across many rows. Randomising the row order makes the roles
of a held-out row exchangeable within this fixed corpus, conditional on separately
fitted objects. It does not establish an independent sample of future wind-tunnel
campaigns, and it does not support a coverage claim about a new airfoil design.


3. Programs
-----------
calibration_calculations.py   11811 bytes
    SHA-256 c2884d2a47fa601b5f1b8aeee35afe4ad6074490cf9b62c71903d6d081ea21a2
uncertainty_experiments.py     8740 bytes
    SHA-256 92463e8a10ed7e338fb3c8af411a4ca5d76fabb020b84fb7b0c941ab6d7c0e19

Unchanged bytes of the content packet's two complete programs. Save all four files
above into one folder and run them in that order. The first writes
checked-results.json; the second imports from it and writes experiment-results.json.
Neither downloads anything or contacts this site.

    py -3.12 -m venv .venv
    .venv\Scripts\python -m pip install numpy==2.3.5 scipy==1.18.1 scikit-learn==1.9.1
    .venv\Scripts\python calibration_calculations.py
    .venv\Scripts\python uncertainty_experiments.py

On macOS or Linux create the environment with python3 -m venv .venv and use
.venv/bin/python in place of .venv\Scripts\python.

Under Python 3.12.14 with NumPy 2.3.5, SciPy 1.18.1 and scikit-learn 1.9.1, both
programs reproduce the content packet's recorded JSON byte for byte. That equality is
rechecked by scripts/verify-calibration-data.py; a different library version may
change the last digits of a fitted optimum and is not claimed to reproduce those
bytes.

The three shorter programs in this directory — reliability_bins.py, monotone_map.py
and conformal_rank.py — are the ones displayed on the page. Each is assembled from
functions copied verbatim out of calibration_calculations.py plus a short driver, and
scripts/verify-calibration-examples.py regenerates and re-executes each of them rather
than trusting a transcription.

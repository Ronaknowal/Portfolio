# English EWT extraction and calculation provenance

Retrieved 12 September 2026. Source release: Universal Dependencies English EWT `r2.16`. [Treebank description](https://universaldependencies.org/treebanks/en_ewt/index.html), [release README](https://raw.githubusercontent.com/UniversalDependencies/UD_English-EWT/r2.16/README.md), [license](https://creativecommons.org/licenses/by-sa/4.0/). `data-sources.json` records the three exact source URLs and SHA-256 of downloaded bytes. Source files were read in memory and were not retained as unnecessary full-corpus copies.

Our derivative `ewt-sequences.json` retains the first120train,40dev,40test sentences whose integer-ID syntactic-word rows number3–15 inclusive. Multiword-token range rows and empty-node decimal rows are excluded; sentence boundaries and `sent_id` remain. Retained fields are split, ID, tokens and original UPOS. No sentence was selected based on model correctness. Counts:1188train tokens,341dev,370test. The lesson's coarse label mapping is NOUN/PROPN→NOUN, VERB/AUX→VERB, all others→OTHER. Original UPOS labels are retained to make the lossy mapping explicit. Release order/short-sentence selection creates a pedagogical subset, not a representative sample. The extract preserves attribution and is offered under the same CC BY-SA4.0 annotation/database terms, subject to the underlying notices above.

The complete compact extraction rule is: split each UTF-8 CoNLL-U source on blank lines; discard comments from row parsing; retain token rows whose ID string is all digits; filter by3≤length≤15; take the first split-specific limit; preserve FORM(column2), UPOS(column4), and `# sent_id`. SourcehashesmakechangesdetectableevenifatagURLismoved. No external download is needed to run the lesson's programs.

`author-calculations.py` is a retained bounded author probe for four-path arithmetic, forward/backward versus enumeration, the logZ derivative, and the prespecified real two-model comparison. It writes `checked-results.json`. Environment actually used: Python3.12.14, NumPy2.3.5, SciPy1.18.1, scikit-learn1.9.1. The shared runtime was read only; no dependency was installed. Both real fits used averaged sequence NLL+.05||theta||², L-BFGS-B maxiter150/ftol1e−11/gtol1e−7; no random initialization or stochastic fit. Both optimizer success flags were true, independent25iterations, chain34. Test metrics for both models exist in author evidence for the fixed comparison; learner selection uses development and prints only the selected model's test result.

The downloadable `crf_example.py` combines the lesson's two code blocks and returns the four learner-needed inference quantities. It was executed on 19 September 2026 in the environment listed above; its development comparison and selected test counts reproduce the author calculations. The native verifier independently enumerates small paths to check the recurrence and checks every stored development prediction. The optional PyTorch/CRFsuite resources are external alternatives; no output from those programs is claimed here.
